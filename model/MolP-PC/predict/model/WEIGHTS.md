# MolP-PC Weights

Place the MolP-PC inference weights in this directory before running the real model.

Required files:

- `Absorption.pth`
- `Distribution.pth`
- `Ecotoxicity.pth`
- `Excretion.pth`
- `LD50.pth`
- `Metabolism.pth`
- `Tox21.pth`
- `Toxicology.pth`

The weight files are intentionally ignored by Git. Track their origin, checksum, license,
and hardware validation evidence in the deployment record instead of committing them.

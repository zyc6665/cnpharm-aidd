# 验证码功能实施计划

## 任务概述
为注册模块添加邮箱验证码功能，支持注册和找回密码场景。

## 需求参数
- 验证码长度：6 位数字
- 有效期：5 分钟
- 发送频率限制：60 秒
- 每日上限：10 次/邮箱
- 存储策略：开发环境→数据库，生产环境→缓存

## 实施步骤

### 1. 配置层扩展 ✅
- `backend/app/config.py`: 添加 SMTP 和验证码配置
- `backend/.env.example`: 添加配置示例
- `backend/.env`: 添加实际配置

### 2. 数据模型 ✅
- `backend/app/models/verification.py`: 验证码模型和每日计数模型
- `backend/app/models/__init__.py`: 导出新模型

### 3. Schema 定义 ✅
- `backend/app/schemas/verification.py`: 验证码相关 Schema
- `backend/app/schemas/users.py`: 添加 verification_code 字段

### 4. 验证码存储服务 ✅
- `backend/app/services/verification/storage.py`: 策略模式存储实现
- `backend/app/services/verification/__init__.py`: 模块初始化

### 5. 邮件服务 ✅
- `backend/app/services/email/sender.py`: 邮件发送服务
- `backend/app/services/email/templates.py`: 邮件模板
- `backend/app/services/email/__init__.py`: 模块初始化

### 6. 验证码核心服务 ✅
- `backend/app/services/verification/service.py`: 核心业务逻辑

### 7. API 端点 ✅
- `backend/app/api/v1/verification.py`: 验证码 API
- `backend/app/api/v1/auth.py`: 修改注册、添加重置密码
- `backend/app/api/v1/__init__.py`: 注册路由

### 8. 依赖更新 ✅
- `backend/requirements.txt`: 添加 aiosmtplib

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/v1/verification/send-code | 发送验证码 |
| POST | /api/v1/verification/verify | 验证验证码（预校验） |
| POST | /api/v1/auth/register | 用户注册（需验证码） |
| POST | /api/v1/auth/reset-password | 重置密码（需验证码） |

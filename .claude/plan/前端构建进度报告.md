**问题描述**：
- 工具创建表单缺失核心配置字段
- 无法创建可执行的工具

**缺失字段**：
```typescript

{
  provider_type: "platform" | "user",  // 工具提供者类型

      endpoint: string,
      method: string,
      headers: object,
      input_schema: object,
      output_schema: object

```

**影响**：
- ❌ 用户无法创建完整的工具
- ❌ 创建的工具无法实际运行
- ❌ 核心业务功能受阻

**位置**：`frontend/src/views/tools/Create.vue`

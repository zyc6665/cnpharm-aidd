## 📐 核心设计要点

### 系统架构

```
前端层 (Vue3)
    ↓ REST API + WebSocket
API网关层 (FastAPI)
    ↓
业务逻辑层 (Services)
    ↓
数据层 (PostgreSQL) + 任务队列 (Celery+Redis) + 对象存储 (MinIO)
    ↓
GPU Worker Pool
```

### 核心功能模块 (7个)

1. **用户认证模块** - JWT + 游客模式
2. **工具管理模块** - 通用工具接入、版本管理
3. **任务管理模块** - 任务CRUD、状态机、队列管理
4. **GPU资源模块** - 检测、分配、监控
5. **文件管理模块** - 上传下载、生命周期管理
6. **积分系统模块** - 接口预留（暂不实现）
7. **监控告警模块** - 健康检查、指标采集

### 数据库设计 (18张表)

- 用户相关：3张表
- 工具相关：5张表
- 任务相关：5张表
- 文件相关：2张表
- GPU资源：2张表
- 系统配置：1张表

### 接口设计 (50+个接口)

- 认证授权：6个
- 工具管理：12个
- 任务管理：10个
- 文件管理：8个
- GPU资源：6个
- 系统管理：8个

### 关键技术点

1. **游客模式实现**
   - 无需注册即可体验
   - 临时session管理
   - 功能和配额限制

2. **GPU资源管理**
   - 自动检测GPU节点（nvidia-smi）
   - 智能分配算法（优先级 + 显存匹配）
   - 实时使用率监控
   - 任务排队机制

3. **任务调度策略**
   - Celery多队列（高优先级、普通、GPU专用）
   - 任务状态机（PENDING → RUNNING → SUCCESS/FAILURE）
   - 失败自动重试
   - 实时进度推送（WebSocket）

4. **通用工具接入**
   ```json
   {
     "type": "remote_api | docker_image | python_script",
     "endpoint": "http://...",
     "input_schema": {...},
     "output_schema": {...},
     "gpu_required": true,
     "gpu_memory_mb": 8000,
     "estimated_time_sec": 300
   }
   ```

5. **文件生命周期管理**
   - SHA256去重
   - 自动清理过期文件（Celery beat）
   - 预签名URL（MinIO）

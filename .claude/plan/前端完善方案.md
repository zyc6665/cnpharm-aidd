### 3.1 目标

- ✅ 用户可以创建完整的工具配置

### 3.2 设计方案

#### 方案架构

```
工具创建表单
├── 基本信息（已实现）
│   ├── name, slug, description
│   ├── category, tags, icon
│   └── gpu_required, timeout_sec

│

│   │   ├── endpoint, method
│   │   └── headers, auth
│   │

│   │   ├── image, command
│   │   └── env_vars, volumes
│   │
│   └── Script配置（type=Script时显示）
│       ├── script_path
│       └── script_args
│
└── 参数定义（新增）⭐
    ├── input_schema（输入参数）
    └── output_schema（输出结果）
```

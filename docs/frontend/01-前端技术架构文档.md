## 1. 项目概述

### 1.1 项目定位

CPUModel 是一个科学计算工具管理平台的前端应用，提供：
- 平台介绍与展示（首页）
- 用户认证与管理
- 科学计算工具浏览与使用
- 计算任务管理与实时进度
- 管理后台

### 1.2 目标用户

| 用户类型 | 使用场景 |
|----------|----------|
| 访客 | 浏览首页、了解平台功能 |
| 普通用户 | 注册登录、使用工具、管理任务 |
| VIP 用户 | 更多配额、优先计算 |
| 管理员 | 后台管理、系统监控 |

### 1.3 浏览器支持

| 浏览器 | 最低版本 |
|--------|----------|
| Chrome | 90+ |
| Firefox | 88+ |
| Safari | 14+ |
| Edge | 90+ |

## 7. 路由设计

```typescript
const routes = [
  // 公开页面
  { path: '/', name: 'Home' },
  { path: '/login', name: 'Login' },
  { path: '/register', name: 'Register' },
  { path: '/tools', name: 'ToolList' },
  { path: '/tools/:id', name: 'ToolDetail' },

  // 需要认证
  { path: '/tasks', name: 'TaskList', meta: { requiresAuth: true } },
  { path: '/tasks/:id', name: 'TaskDetail', meta: { requiresAuth: true } },
  { path: '/user/*', meta: { requiresAuth: true } },

  // 管理后台
  { path: '/admin/*', meta: { requiresAuth: true, requiresAdmin: true } },

  // 错误页面
  { path: '/:pathMatch(.*)*', name: '404' },
]
```

# CPUModel 核心页面 UI 设计方案

**版本**: v2.0
**日期**: 2025-12-17
**设计参考**: SciMiner Platform (https://sciminer.tech/)

---

## 设计理念

基于 SciMiner 成熟的科学计算平台 UI/UX 设计,结合 CPUModel 的业务特点,打造简洁、专业、易用的科研工具平台界面。

**核心设计原则:**
- **降低使用门槛**: 支持游客模式,提供参数示例
- **信息层次清晰**: 卡片化布局,突出关键信息
- **任务全程可追溯**: 完整的任务生命周期管理
- **响应式设计**: 支持桌面端和移动端访问

表单验证规则 (参考 SciMiner):
- 用户名: 3-20字符, 支持中英文/数字/下划线
- 邮箱: 有效格式, 建议学校/企业邮箱
- 密码: 8+ 字符, 必须包含字母和数字
- 验证码: 6位数字, 邮箱验证

密码强度指示器:
- 弱 (红色): 纯数字或纯字母
- 中 (橙色): 字母+数字
- 强 (绿色): 字母+数字+特殊字符, 12+字符

交互细节:
- 实时验证: 失焦时验证,错误提示在输入框下方
- 验证码倒计时: 发送后60秒内不可重复发送
- 邀请码: 选填项,折叠显示,点击展开

## 6. 设计规范总结

**参考**: SciMiner 设计体系

### 6.1 色彩系统

```
主色调:
- Primary: #1890ff (科技蓝)
- Success: #52c41a (成功绿)
- Warning: #faad14 (警告橙)
- Error: #f5222d (错误红)
- Info: #13c2c2 (信息青)

中性色:
- Text-Primary: #262626
- Text-Secondary: #8c8c8c
- Border: #d9d9d9
- Background: #f5f5f5
- White: #ffffff
```

### 6.2 排版规范

```
字号:
- H1: 28px (页面标题)
- H2: 24px (区块标题)
- H3: 20px (卡片标题)
- Body: 14px (正文)
- Caption: 12px (辅助信息)

字重:
- Regular: 400
- Medium: 500
- Bold: 600

行高:
- Title: 1.2
- Body: 1.5
- Caption: 1.4
```

### 6.3 间距系统

```
8px 基础单位:
- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px
- xl: 32px
- xxl: 48px
```

### 6.4 响应式断点

```
| 断点 | 宽度 | 布局变化 |
|------|------|----------|
| xs | < 576px | 单列,侧边栏隐藏 |
| sm | ≥ 576px | 单列/双列 |
| md | ≥ 768px | 双列,侧边栏可收起 |
| lg | ≥ 992px | 三列,完整侧边栏 |
| xl | ≥ 1200px | 四列 |
| xxl | ≥ 1600px | 内容最大宽度 1400px |
```

### 6.5 动效规范

```
过渡时间:
- Fast: 0.15s (小元素悬停)
- Normal: 0.3s (卡片/按钮)
- Slow: 0.5s (页面切换)

缓动函数:
- Ease: cubic-bezier(0.25, 0.1, 0.25, 1)
- Ease-in-out: cubic-bezier(0.42, 0, 0.58, 1)
```

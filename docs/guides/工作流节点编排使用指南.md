# 工作流节点编排使用指南

本文说明 `/workflow` 页面中的模板式节点编排功能。第一版采用固定模板，用户按节点逐步配置和运行工具；后续可升级为自由拖拽画布。

## 功能范围

当前版本支持：

- 选择预设工作流模板。
- 在画布中查看节点、连线和状态。
- 点击节点查看工具、输入、输出和任务结果。
- 为工具节点选择可用工具。
- 从节点面板提交当前节点任务。
- 根据上游节点任务产物推荐下游输入。

当前版本暂不支持：

- 自由新增或删除节点。
- 手动拖拽节点位置。
- 自定义连线。
- 一键运行完整流程。
- 后端保存自定义模板。

## 页面结构

`/workflow` 的手动模式由三部分组成：

- 左侧 `template-step-rail`：模板选择和节点列表。
- 中间 `WorkflowTemplateCanvas`：固定节点画布，展示节点和连线。
- 右侧 `WorkflowNodeInspector`：节点详情、工具选择、输入产物、任务结果和运行按钮。

智能体模式仍保留 `AiddAgentPanel`。

## 节点状态

节点状态来自 `frontend/src/workflow/template-state.ts`：

- `idle`：输入未准备好。
- `ready`：工具和输入满足运行条件。
- `running`：关联任务运行中。
- `completed`：关联任务成功。
- `failed`：关联任务失败或取消。
- `needs_tool_selection`：节点有多个工具但尚未选择。
- `invalidated`：预留给上游更新后下游结果失效的场景。

## 开发者说明

核心文件：

- `frontend/src/workflow/template-types.ts`：模板、节点和边的数据模型。
- `frontend/src/workflow/templates.ts`：内置模板定义。
- `frontend/src/workflow/template-state.ts`：节点状态计算。
- `frontend/src/workflow/template-artifacts.ts`：上游产物推荐。
- `frontend/src/stores/workflow.ts`：模板会话状态、节点工具、节点任务和产物绑定。
- `frontend/src/components/workflow/WorkflowTemplateCanvas.vue`：画布容器。
- `frontend/src/components/workflow/WorkflowCanvasNode.vue`：节点组件。
- `frontend/src/components/workflow/WorkflowCanvasEdge.vue`：连线组件。
- `frontend/src/components/workflow/WorkflowNodeInspector.vue`：右侧节点面板。

## 新增模板步骤

1. 在 `template-types.ts` 中确认节点类型和语义产物类型是否够用。
2. 在 `templates.ts` 新增 `WorkflowTemplate`。
3. 每个节点必须有稳定 `id`、`type`、`titleKey` 和 `position`。
4. 工具节点用 `toolSlugs` 绑定平台工具 slug。
5. 用 `edges` 表达输入输出依赖，并设置 `artifactType`。
6. 补充 `frontend/test/workflow-templates.test.ts` 或新增测试。

# AI 制药平台文档完善设计

## 目标

将现有平台文档从“平台工程能力基线”完善为“可支持药物研发决策的产品基线”，明确版本口径、科学结果语义、模型验证门禁和实验反馈闭环。

## 设计范围

1. 在交付需求中统一 V1/V1.1 对 ADMET 的定义，并补齐候选分子筛选、比较、报告和实验结果回写需求。
2. 新增药研数据与科学结果规范，定义分子、预测、实测、评分和不确定性字段。
3. 新增模型卡与科学验证发布门禁规范，区分平台契约验证、运行验证和科学验证。
4. 新增 DMTA 实验反馈闭环路线，保持与暂不替代 LIMS/ELN 的范围约束一致。
5. 更新 Artifact、Tool Contract、功能模块、验收流程和文档索引，建立可追踪关系。

## 关键决策

- V1 仅交付基础 ADMET 的单工具运行、结果落库和可下载；多模型比较、批量筛选和质量看板归入 V1.1。
- 预测结果必须记录 endpoint、单位、方向、模型版本、权重摘要、输入版本和不确定性状态。
- 对接和多模型评分不得默认跨工具直接比较；必须声明 score definition 和归一化规则。
- 实验结果以标准 Artifact 回写，先支持 CSV/JSON 导入和预测-实测关联，不把平台扩展为完整 ELN/LIMS。
- 文档更新不代表代码功能已实现；所有新增能力使用 Draft/Planned 口径，验收报告继续保留真实证据等级。

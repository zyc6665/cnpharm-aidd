# 科研白板功能退役设计

## 目标

从当前产品中移除科研白板入口和运行能力，保留 Artifact、Workflow、蛋白制备工具和外部数据库 Artifact 导入等独立能力。

## 边界

- 移除白板列表与画布页面、全局和项目导航入口、白板路由、白板 API 及项目/工作台白板聚合数据。
- 移除蛋白制备写入白板节点的 API 适配；蛋白制备作为内置工具和 Workflow 节点继续可用。
- 外部数据库导入继续生成 Artifact，移除其可选白板目标和画布节点副作用。
- 保留 `research_boards` 表、ORM 模型和历史数据，不创建删除表或清空数据的迁移；保留项目迁移与用户/项目删除中的旧数据清理。
- 移除白板专属 Feature Flag。历史设计文档可保留为历史记录，当前产品需求文档需反映已退役状态。

## 方案

删除产品入口和可调用的白板路由，不采用只隐藏前端的方式。持久化模型仅作为历史数据兼容层继续存在，不再被新功能写入或读取展示。Workflow、Artifact 和通用蛋白制备链路维持现有边界。

## 验收

- 前端导航、路由、项目总览与工作台响应均不再包含白板入口或数据。
- `/research-boards/*` 与白板专属蛋白制备同步路由不再注册。
- 外部数据库导入仍返回持久化后的 Artifact，但不接受 `board_id`、不修改白板内容。
- 数据库迁移历史仍包含 `research_boards`，应用代码保留旧行清理能力。
- 前端构建、后端编译和差异格式检查通过。

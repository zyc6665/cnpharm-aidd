# Workflow Canvas-first Workbench Design

## 背景

当前工作流页仍是传统页面堆叠结构：顶部定义栏、运行输入、历史、预检、三列画布、底部结果中心依次排列。画布只占页面中部，节点固定为 `188px x 112px` 的小卡片，只能展示类型、标题和状态。对于药物研发平台，PDB、Ligand、ADMET、对接、MD、重排打分等节点都需要承载参数、运行状态、产物和可视化，小节点表达能力不足。

用户希望将工作流升级为画布优先的科研工作台：画布占据主要空间，节点升级为面板集合，节点内部能够直接运行、配置和预览结果；工具库和结果中心变成可缩放侧边栏。

## 目标

- 让工作流页成为单屏画布工作台，而不是纵向堆叠页面。
- 将工具节点从小卡片升级为可配置、可运行、可预览的节点面板。
- 将 PDB、Ligand、对接结果、ADMET 表格等可视化直接嵌入节点面板。
- 将工具库、控制节点、结果中心、Artifact、运行历史整合进可折叠、可拖拽缩放侧边栏。
- 复用现有独立节点运行、任务轮询、Artifact、结果可视化组件，避免重做业务逻辑。

## 非目标

- 不在第一版重做后端工作流执行协议。
- 不在第一版引入新的大型画布引擎。
- 不在第一版渲染所有节点的重型 3D 可视化。
- 不把所有旧面板一次性删除，先迁移核心路径，保留回退空间。

## 推荐方案：Canvas-first 工作台

采用全画布工作台结构：顶部保留紧凑命令栏，左侧是工具库侧边栏，右侧是结果中心侧边栏，中间是可平移缩放画布。画布节点变成较大的科研面板，节点内直接呈现工具名、运行状态、参数摘要、输入产物、输出产物、运行按钮和内联预览。

该方案最符合药物研发工作流场景：用户不是只在编排 DAG，而是在画布上完成查询、准备、计算、查看结果和继续下游步骤。

## 替代方案

### 方案 B：中央画布 + 底部详情面板

保留中央画布，节点仍较轻，选中节点后在底部面板展示配置、结果和可视化。该方案改动较小，但画布节点本身仍然不承载工作过程，不符合“节点面板集合”的目标。

### 方案 C：小节点 + 点击展开浮层

保留现有小节点，点击或双击弹出大面板。该方案风险最低，但交互割裂，可视化仍然离开画布，不适合作为长期主交互。

## 页面结构

### 顶部命令栏

顶部命令栏高度控制在约 48 到 56 像素，承载：

- 工作流名称和保存状态。
- 运行整条工作流按钮。
- 当前运行、成功、失败、待配置节点计数。
- 画布缩放、适配视图、可选的导出入口。

命令栏不再占用大块页面高度，避免压缩画布。

### 左侧工具栏

左侧栏默认宽度约 320 像素，允许拖拽缩放到 280 到 480 像素，允许折叠为窄图标栏。内容包括：

- 工具库搜索。
- 工具分类、输入类型、输出类型、执行器过滤。
- 控制节点列表。
- 拖拽工具到画布创建节点。

现有 `WorkflowToolPalette` 和 `WorkflowControlNodePalette` 可以复用为侧边栏内容。

### 右侧结果中心

右侧栏默认宽度约 380 像素，允许拖拽缩放到 320 到 560 像素，允许折叠。内容以标签页组织：

- 当前节点结果。
- Workflow 结果摘要。
- Artifact 中心。
- 运行历史。
- 日志和错误详情。

现有 `WorkflowTaskResultPanel`、`WorkflowResultsReportPanel`、`WorkflowArtifactPanel` 可以迁移进此侧栏。

### 中央画布

中央画布占据剩余全部空间，保留现有拖拽添加节点、节点移动、连线、缩放能力。第一版继续使用当前画布实现，避免引入新引擎；节点尺寸和连线端点逻辑按新面板尺寸调整。

## 节点面板设计

节点默认从小卡片升级为面板，建议默认尺寸约 `380px x 280px`，后续支持紧凑、标准、展开三种显示状态。

### 节点头部

- 工具名称或节点名称。
- 工具类型、执行器、资源标签。
- 状态徽标：待配置、就绪、运行中、成功、失败。
- 运行当前节点按钮。
- 删除、展开、更多操作按钮。

### 节点主体

节点主体用轻量标签或分区承载：

- 输入：关键参数摘要、上传文件、已选择 Artifact。
- 预览：PDB、Ligand、表格、JSON、报告摘要等内联展示。
- 输出：产物文件、标准 Artifact 类型、下载入口。
- 日志：运行进度、最近日志、错误提示。

第一版应优先展示“输入摘要 + 状态 + 输出摘要 + 选中节点预览”，避免每个节点都渲染完整复杂表单。

## 可视化策略

重型可视化必须懒加载：

- 只有选中节点、展开节点或节点预览标签激活时，才加载 Mol*、3D ligand、MD 轨迹等重型组件。
- 非选中节点展示缩略信息、文件名、结构类型、关键指标。
- 表格、JSON、文本结果可以直接轻量预览。
- 失败节点展示错误摘要和查看日志入口。

这能保证画布上同时存在多个节点时仍然流畅。

## 交互设计

- 从左侧工具库拖拽工具到画布创建节点。
- 点击节点选中，并同步右侧结果中心上下文。
- 节点内可以直接运行当前节点，复用现有 `/tasks` 独立任务创建链路。
- 节点运行后绑定 `taskByNode[node.id]`，结果中心和节点面板读取同一份任务状态。
- 点击结果中心 Artifact 可以定位并选中来源节点。
- 侧边栏宽度和折叠状态持久化到本地 UI 状态。

## 技术架构

建议新增或调整以下前端模块：

- `WorkflowWorkbenchShell.vue`：工作台总布局，负责顶部栏、左右侧栏和画布区域组合。
- `WorkflowWorkbenchHeader.vue`：紧凑命令栏。
- `ResizableWorkbenchSidebar.vue`：可折叠、可拖拽缩放侧边栏。
- `WorkflowCanvasPanelNode.vue`：新的节点面板视图，逐步替代小节点视图。
- `WorkflowNodeInlinePreview.vue`：节点内结果预览适配层。
- `useStandaloneNodeRun.ts`：从 `WorkflowNodeRunPanel.vue` 抽出独立节点运行、上传、轮询逻辑，供节点面板和详情面板复用。
- `useWorkflowWorkbenchLayout.ts`：管理侧边栏宽度、折叠状态、节点显示模式等 UI 状态。

现有 `WorkflowCanvasBoard.vue` 第一版继续保留，调整节点尺寸常量、节点组件插槽和边端点计算即可。

## 数据流

- `frontend/src/views/workflow/index.vue` 继续负责加载 workflow、tools、artifacts、runs。
- 工作台 Shell 接收节点、边、工具列表、Artifact、任务映射、项目 ID。
- 节点面板根据 `node.id` 获取 `taskByNode[node.id]`。
- 节点预览根据任务输出和 Artifact 列表解析可展示内容。
- 独立运行成功后更新 `workflowStore.recordNodeTask`，刷新 Artifact store。
- 任务轮询上移到工作台层，恢复所有未终止节点任务，避免只有打开配置面板时才刷新状态。

## 错误处理

- 工具未选择：节点面板显示选择工具入口，不允许运行。
- 参数缺失：节点面板展示字段级错误，并保留当前输入。
- 上传失败：显示上传错误，不创建任务。
- 任务失败：节点面板和右侧结果中心同时显示失败状态、错误消息和日志入口。
- Artifact 不可预览：展示文件名、类型、下载入口，不阻断流程。

## 测试策略

- 为 `ResizableWorkbenchSidebar` 添加组件测试：折叠、展开、拖拽宽度边界。
- 为 `WorkflowCanvasPanelNode` 添加组件测试：展示状态、运行按钮、输入摘要、输出摘要。
- 为节点内独立运行逻辑添加回归测试：点击节点运行后创建任务、绑定节点、轮询终态。
- 为 `WorkflowNodeInlinePreview` 添加轻量测试：PDB/Ligand/表格/不可预览 Artifact 的分支。
- 保留并扩展现有 `WorkflowCanvasBoard.spec.ts`、`WorkflowToolPalette.spec.ts`、`WorkflowNodeRunPanel.spec.ts`。
- 运行 `npm test -- <相关 spec>` 和 `npm run build`。

## 实施顺序

1. 搭建 `WorkflowWorkbenchShell` 和左右可缩放侧栏，先迁移现有工具库与结果中心。
2. 调整 `WorkflowCanvasBoard` 支持大节点面板尺寸和更大的画布工作区。
3. 新增 `WorkflowCanvasPanelNode`，保留节点拖拽、选择、连线和删除能力。
4. 抽出 `useStandaloneNodeRun`，让节点面板直接运行当前节点。
5. 新增 `WorkflowNodeInlinePreview`，先接入轻量预览和选中节点的结构可视化。
6. 将未终止节点任务轮询上移到工作台层。
7. 做视觉 polish、响应式处理和测试补齐。

## 验收标准

- 工作流页首屏以画布为主体，工具库和结果中心是可折叠、可缩放侧边栏。
- 工具节点以面板形式显示，不再只是小节点。
- 节点面板内可以看到状态、运行入口、输入摘要、输出摘要和结果预览。
- PDB/Ligand 等可视化能在选中节点面板内展示。
- 节点独立运行后，节点状态和右侧结果中心能同步更新。
- 旧的工具拖拽、节点移动、连线、删除、结果查看能力不回退。
- 前端相关测试和生产构建通过。

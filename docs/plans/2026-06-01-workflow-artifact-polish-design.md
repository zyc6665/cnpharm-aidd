# 工作台产物路径交互打磨设计

## 目标

在不改变现有四级数据层级规则的前提下，把工作台中的产物复用与浏览体验从“能用”打磨成“顺手”：

- 左侧参数选择器从并列四个下拉，改成 `路径条 + 单层选择`
- 右侧产物面板从静态四级堆叠，改成 `分组浏览 + 路径展开`
- 左右两侧共享同一套来源路径，并支持反向定位

本次只改交互层，不改后端接口，也不改前端共享层级派生器的核心归属规则。

## 背景

当前四级层级已经落地：

- `工具分组 -> 工具 -> 任务 -> 任务产物`

但交互上还有两个明显问题：

### 1. 左侧参数选择器信息密度太高

[frontend/src/components/tools/ArtifactFilePicker.vue](/data/zhouyc/cpumodel_sciminer/frontend/src/components/tools/ArtifactFilePicker.vue) 现在把四级都做成并列选择框，虽然功能完整，但存在：

- 同时出现四个控件，视觉负担重
- 用户不容易感知自己当前正在选择哪一层
- 回退修改路径时，需要重新理解多个下拉间的联动

### 2. 右侧产物面板层级能看见，但浏览节奏不自然

[frontend/src/components/workflow/WorkflowArtifactPanel.vue](/data/zhouyc/cpumodel_sciminer/frontend/src/components/workflow/WorkflowArtifactPanel.vue) 已经基于四级树渲染，但仍然是静态展开式浏览：

- 分组、工具、任务、产物都同时出现
- 当数据变多时，纵向长度会快速膨胀
- 左右两侧虽然用的是同一棵树，但缺少“点击右边，定位左边”的联动

## 核心设计决策

### 1. 左侧选择器改成“路径条 + 当前层列表”

左侧不再同时渲染四个平级下拉，而是改成：

- 顶部一条可点击回退的路径条
- 中间一个当前层候选列表
- 底部一个已选产物摘要

路径条形态：

- `工具分组 / 工具 / 任务 / 产物`
- 已完成层级显示真实值
- 未完成层级显示占位文案
- 点击任意已完成层级，可以回退到该层，并清空其后的选择

当前层候选列表规则：

- 若还未选分组：展示分组列表
- 已选分组未选工具：展示工具列表
- 已选工具未选任务：展示任务列表
- 已选任务未选产物：展示产物列表

这样用户任何时刻只需要处理“一层”的决策。

### 2. 右侧面板改成分组展开式浏览

右侧面板改成三段式浏览节奏：

- 分组是一级章节
- 工具是二级折叠节点
- 任务是三级摘要卡
- 产物在任务节点展开后才出现

不引入重量级树组件，继续用当前页面已有卡片语义做轻折叠：

- 结构轻
- 更容易保持现有视觉一致性
- 后续要做高亮与同步更容易

### 3. 左右两侧共享路径定位能力

新增一个轻量同步机制：

- 左侧选中某个产物时，保留其完整路径状态
- 右侧点击任务或产物时，向父级发出“定位到路径”的事件
- 左侧接到路径后，直接同步为：
  - `groupId`
  - `toolSlug`
  - `taskId`
  - `artifactId`

这不是全局状态重构，只是在工作台页内部建立一条受控同步链路。

### 4. 默认定位优先利用当前上下文

参数选择器打开时，优先定位：

1. 当前工作台分组
2. 当前工具
3. 若已有已选产物，则优先回填完整路径

右侧面板默认展开：

1. 当前分组
2. 当前工具
3. 当前工具最近有产物的任务

这样可以减少首次点击成本。

## 组件设计

### 1. ArtifactFilePicker

建议在现有组件基础上增加以下状态：

- `activeStep: 'group' | 'tool' | 'task' | 'artifact'`
- `highlightArtifactId?: string`

模板结构改为三段：

- `artifact-path`
- `artifact-step-panel`
- `artifact-selection-summary`

候选项统一渲染成轻量按钮卡：

- 左侧是标题
- 右侧是数量或时间摘要
- 当前选中态高亮

### 2. WorkflowArtifactPanel

新增本地展开状态：

- `expandedGroupIds`
- `expandedToolSlugs`
- `expandedTaskIds`

并基于当前上下文自动初始化默认展开。

增加点击行为：

- 点击工具节点：展开/收起工具
- 点击任务节点：展开/收起任务
- 点击产物：触发 `select-artifact-path`

### 3. Workflow 页面协调

[frontend/src/views/workflow/index.vue](/data/zhouyc/cpumodel_sciminer/frontend/src/views/workflow/index.vue) 或工作台运行面板需要承担最小协调职责：

- 保存最近一次从右侧面板选中的路径
- 把路径传入左侧参数选择器
- 不把这套状态下沉到 Pinia，避免引入无必要全局状态

## 空状态与异常路径

### 1. 空状态

- 无任何兼容产物：提示先运行上游工具
- 分组存在但无兼容产物：显示空分组说明，不直接消失
- 任务存在但无兼容产物：显示不可选说明

### 2. 路径失效

如果 `accept` 或当前上下文变化，导致已选产物不再有效：

- 保留到可确认的最高有效层级
- 优先保留到任务层
- 清空最终产物
- 给出轻提示，而不是整棵路径直接消失

## 测试策略

继续保留现有四级树纯函数测试，保证本次不改坏数据归属和排序规则。

### 2. 组件表面测试

新增表面断言覆盖：

- 左侧存在路径条、单层列表、摘要区
- 右侧存在分组/工具/任务折叠结构
- 左右存在路径同步入口

## 非目标

本次不做：

- 后端接口调整
- 任务与产物权限模型改造
- 工作台全局状态重构
- 全站 UI 重做
- 新的拖拽、搜索、批量操作能力

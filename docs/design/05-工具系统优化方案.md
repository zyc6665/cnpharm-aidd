## 1. 概述

### 1.1 背景与目标

#### 当前问题

现有系统的工具管理存在以下局限：

1. **创建权限单一**：仅管理员可创建工具，无法发挥社区共建优势
2. **无法区分来源**：缺少字段区分平台官方工具与用户贡献工具
3. **缺乏审核机制**：用户创建的工具无法经过审核后公开
4. **工具视图单一**：前端仅有"公开工具"视图，无法展示用户自己的工具

#### 优化目标

1. **开放工具创建**：允许注册用户创建自己的计算工具
2. **区分工具来源**：明确标识平台官方工具与用户贡献工具
3. **引入审核机制**：用户工具需审核后才能公开
4. **丰富工具视图**：提供公开工具、我的工具、收藏工具三类视图

### 1.2 参考系统

参考 **SciMiner 科学文献挖掘平台** 的工具管理模式：

| 特性 | SciMiner 实现 | 本平台规划 |
|-----|--------------|-----------|
| 工具分类 | 公开/定制/收藏 | 公开/我的/收藏 |
| 用户创建 | 支持 | 支持 |
| 版本管理 | 支持 | 保留现有设计 |
| 工具配置 | FastAPI Schema | JSON Schema |
| 审核机制 | 有 | 新增 |

## 2. 数据库优化设计

### 2.1 新增枚举类型

#### 2.1.1 工具提供者类型 (ToolProviderType)

```sql
-- 工具提供者类型枚举
CREATE TYPE tool_provider_type AS ENUM (
    'platform',     -- 平台官方工具
    'user'          -- 用户贡献工具
);

COMMENT ON TYPE tool_provider_type IS '工具提供者类型：platform=平台官方, user=用户贡献';
```

#### 2.1.2 工具审核状态 (ToolReviewStatus)

```sql
-- 工具审核状态枚举
CREATE TYPE tool_review_status AS ENUM (
    'not_required',    -- 无需审核（平台官方工具）
    'pending',         -- 待审核
    'approved',        -- 已通过
    'rejected'         -- 已拒绝
);

COMMENT ON TYPE tool_review_status IS '工具审核状态：not_required=无需审核, pending=待审核, approved=已通过, rejected=已拒绝';
```

### 2.2 新增字段

#### 2.2.1 tools 表新增字段

| 字段名 | 数据类型 | 默认值 | 说明 |
|-------|---------|-------|------|
| `provider_type` | tool_provider_type | 'user' | 工具提供者类型 |
| `review_status` | tool_review_status | 'pending' | 审核状态 |
| `reviewed_at` | TIMESTAMPTZ | NULL | 审核时间 |
| `reviewed_by` | UUID | NULL | 审核人ID（外键关联users） |
| `reject_reason` | TEXT | NULL | 拒绝原因 |

### 2.3 表结构变更

#### 2.3.1 tools 表完整结构（变更后）

```sql
-- 工具主表（优化后）
CREATE TABLE tools (
    -- 主键
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

    -- 基本信息
    code VARCHAR(50) NOT NULL,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    icon VARCHAR(255),
    category VARCHAR(50),

    -- === 新增字段 ===
    provider_type tool_provider_type NOT NULL DEFAULT 'user',
    review_status tool_review_status NOT NULL DEFAULT 'pending',
    reviewed_at TIMESTAMPTZ,
    reviewed_by UUID REFERENCES users(id) ON DELETE SET NULL,
    reject_reason TEXT,
    -- === 新增字段结束 ===

    -- 版本管理
    current_version_id UUID,

    -- 所有者（关联到创建者）
    owner_id UUID NOT NULL REFERENCES users(id) ON DELETE RESTRICT,

    -- 资源配置
    gpu_required BOOLEAN NOT NULL DEFAULT FALSE,
    gpu_memory_mb INTEGER DEFAULT 0,
    timeout_sec INTEGER DEFAULT 3600,

    -- 统计字段
    usage_count INTEGER NOT NULL DEFAULT 0,
    view_count INTEGER NOT NULL DEFAULT 0,
    favorite_count INTEGER NOT NULL DEFAULT 0,

    -- 状态与可见性
    status tool_status NOT NULL DEFAULT 'draft',
    is_public BOOLEAN NOT NULL DEFAULT FALSE,

    -- 时间戳
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    deleted_at TIMESTAMPTZ,

    -- 约束
    CONSTRAINT uk_tools_code UNIQUE (code) WHERE deleted_at IS NULL
);

-- 字段注释
COMMENT ON COLUMN tools.provider_type IS '工具提供者类型：platform=平台官方, user=用户贡献';
COMMENT ON COLUMN tools.review_status IS '审核状态：not_required=无需审核, pending=待审核, approved=已通过, rejected=已拒绝';
COMMENT ON COLUMN tools.reviewed_at IS '审核时间';
COMMENT ON COLUMN tools.reviewed_by IS '审核人ID';
COMMENT ON COLUMN tools.reject_reason IS '拒绝原因（仅rejected状态有值）';
```

### 2.4 索引优化

#### 2.4.1 新增索引

```sql
-- 按提供者类型查询（首页展示官方工具）
CREATE INDEX idx_tools_provider_type ON tools(provider_type) WHERE deleted_at IS NULL;

-- 按审核状态查询（管理员审核列表）
CREATE INDEX idx_tools_review_status ON tools(review_status) WHERE deleted_at IS NULL;

-- 用户的工具列表（我的工具）
CREATE INDEX idx_tools_owner_id ON tools(owner_id) WHERE deleted_at IS NULL;

-- 复合索引：公开的已审核用户工具
CREATE INDEX idx_tools_public_approved ON tools(is_public, provider_type, review_status)
WHERE deleted_at IS NULL AND is_public = TRUE;

-- 复合索引：平台官方工具
CREATE INDEX idx_tools_platform ON tools(provider_type, status)
WHERE deleted_at IS NULL AND provider_type = 'platform';
```

### 2.5 业务逻辑约束

#### 2.5.1 审核状态自动设置触发器

```sql
-- 平台官方工具自动设置为无需审核
CREATE OR REPLACE FUNCTION set_tool_review_status()
RETURNS TRIGGER AS $$
BEGIN
    IF NEW.provider_type = 'platform' THEN
        NEW.review_status := 'not_required';
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER tr_tools_set_review_status
BEFORE INSERT OR UPDATE OF provider_type ON tools
FOR EACH ROW
EXECUTE FUNCTION set_tool_review_status();
```

#### 2.5.2 工具可见性约束

```sql
-- 用户工具必须审核通过才能公开
ALTER TABLE tools ADD CONSTRAINT chk_tools_public_review
CHECK (
    -- 平台官方工具可直接公开
    (provider_type = 'platform') OR
    -- 用户工具需审核通过才能公开
    (provider_type = 'user' AND (is_public = FALSE OR review_status = 'approved'))
);
```

### 3.2 工具审核流程

```
                    ┌─────────────┐
                    │  用户创建   │
                    │   工具      │
                    └─────┬───────┘
                          │
                          ▼
                    ┌─────────────┐
                    │  草稿状态   │
                    │  (draft)    │
                    └─────┬───────┘
                          │ 用户完善配置
                          ▼
                    ┌─────────────┐
                    │  提交审核   │───────┐
                    │  (pending)  │       │
                    └─────┬───────┘       │
                          │               │
              ┌───────────┼───────────┐   │ 修改后重新提交
              │           │           │   │
              ▼           │           ▼   │
        ┌─────────┐       │     ┌─────────┐
        │  通过   │       │     │  拒绝   │
        │(approved)       │     │(rejected)├───┘
        └────┬────┘       │     └─────────┘
             │            │
             │            │ 管理员可设置
             │            │
             ▼            ▼
        ┌─────────────────────┐
        │    可选：公开       │
        │  (is_public=true)   │
        └─────────────────────┘
```

### 3.3 状态流转规则

| 当前状态 | 可流转到 | 操作者 | 备注 |
|---------|---------|-------|------|
| pending | approved | 管理员 | 审核通过 |
| pending | rejected | 管理员 | 审核拒绝，需填写原因 |
| rejected | pending | 工具所有者 | 修改后重新提交 |
| approved | rejected | 管理员 | 下架工具 |

## 4. API 接口变更

### 4.1 新增接口

#### 4.1.1 获取我的工具列表

```
GET /api/v1/tools/my
```

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| status | string | 否 | 筛选状态 |
| review_status | string | 否 | 筛选审核状态 |
| page | int | 否 | 页码，默认1 |
| page_size | int | 否 | 每页数量，默认20 |

**响应示例**：
```json
{
    "code": 200,
    "message": "success",
    "data": {
        "items": [
            {
                "id": "uuid-xxx",
                "name": "我的工具",
                "provider_type": "user",
                "review_status": "pending",
                "is_public": false,
                "created_at": "2025-12-18T10:00:00Z"
            }
        ],
        "total": 1,
        "page": 1,
        "page_size": 20
    }
}
```

#### 4.1.2 提交工具审核

```
POST /api/v1/tools/{id}/submit-review
```

**权限要求**：工具所有者

**前置条件**：
- 工具状态为 `draft` 或 `published`
- 审核状态为 `pending` 或 `rejected`
- 工具配置完整（有可用版本）

**响应示例**：
```json
{
    "code": 200,
    "message": "审核申请已提交",
    "data": {
        "id": "uuid-xxx",
        "review_status": "pending"
    }
}
```

#### 4.1.3 审核工具（管理员）

```
POST /api/v1/admin/tools/{id}/review
```

**请求体**：
```json
{
    "action": "approve",  // approve | reject
    "reject_reason": ""   // 拒绝时必填
}
```

**响应示例**：
```json
{
    "code": 200,
    "message": "审核完成",
    "data": {
        "id": "uuid-xxx",
        "review_status": "approved",
        "reviewed_at": "2025-12-18T10:00:00Z"
    }
}
```

#### 4.1.4 设置为平台官方工具（管理员）

```
POST /api/v1/admin/tools/{id}/set-platform
```

**请求体**：
```json
{
    "is_platform": true  // true=设为官方, false=取消官方
}
```

### 4.2 变更接口

#### 4.2.1 创建工具接口变更

**原接口**：`POST /api/v1/tools` （仅管理员）

**变更后**：`POST /api/v1/tools` （注册用户可用）

**变更点**：
1. 移除 `get_admin_user` 依赖，改为 `get_current_user`
2. 自动设置 `owner_id = current_user.id`
3. 根据用户角色设置 `provider_type`:
   - 管理员创建默认 `platform`
   - 普通用户创建默认 `user`

**新增请求字段**：
| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| provider_type | string | 否 | 仅管理员可指定，默认根据角色自动设置 |

#### 4.2.2 获取工具列表接口变更

**原接口**：`GET /api/v1/tools`

**变更后**：新增查询参数

| 参数 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| provider_type | string | 否 | 筛选工具来源：platform/user |
| view | string | 否 | 视图类型：public/my/favorites |

**响应新增字段**：
```json
{
    "provider_type": "platform",
    "review_status": "not_required",
    "provider_label": "官方"  // 前端展示用：官方/社区
}
```

```python
"""Add tool provider and review fields

Revision ID: xxx
Create Date: 2025-12-18
"""
from alembic import op
import sqlalchemy as sa

def upgrade():
    # 1. 创建枚举类型
    op.execute("""
        CREATE TYPE tool_provider_type AS ENUM ('platform', 'user');
        CREATE TYPE tool_review_status AS ENUM ('not_required', 'pending', 'approved', 'rejected');
    """)

    # 2. 添加新字段
    op.add_column('tools', sa.Column('provider_type',
        sa.Enum('platform', 'user', name='tool_provider_type'),
        nullable=False, server_default='user'))

    op.add_column('tools', sa.Column('review_status',
        sa.Enum('not_required', 'pending', 'approved', 'rejected', name='tool_review_status'),
        nullable=False, server_default='pending'))

    op.add_column('tools', sa.Column('reviewed_at', sa.DateTime(timezone=True)))
    op.add_column('tools', sa.Column('reviewed_by', sa.String(36)))
    op.add_column('tools', sa.Column('reject_reason', sa.Text()))

    # 3. 添加外键约束
    op.create_foreign_key(
        'fk_tools_reviewed_by', 'tools', 'users',
        ['reviewed_by'], ['id'], ondelete='SET NULL'
    )

    # 4. 创建索引
    op.create_index('idx_tools_provider_type', 'tools', ['provider_type'])
    op.create_index('idx_tools_review_status', 'tools', ['review_status'])

    # 5. 迁移现有数据：将所有现有工具设为平台官方工具
    op.execute("""
        UPDATE tools
        SET provider_type = 'platform',
            review_status = 'not_required'
        WHERE deleted_at IS NULL;
    """)

def downgrade():
    # 1. 删除索引
    op.drop_index('idx_tools_provider_type')
    op.drop_index('idx_tools_review_status')

    # 2. 删除外键
    op.drop_constraint('fk_tools_reviewed_by', 'tools')

    # 3. 删除字段
    op.drop_column('tools', 'reject_reason')
    op.drop_column('tools', 'reviewed_by')
    op.drop_column('tools', 'reviewed_at')
    op.drop_column('tools', 'review_status')
    op.drop_column('tools', 'provider_type')

    # 4. 删除枚举类型
    op.execute("DROP TYPE tool_review_status;")
    op.execute("DROP TYPE tool_provider_type;")
```

| 新字段默认值冲突 | 低 | 中 | 使用合理默认值，分批更新 |
| API 不兼容 | 中 | 高 | 前后端同步发布，版本控制 |
| 审核流程复杂 | 中 | 低 | 简化流程，提供管理工具 |

### 7.2 实施建议

1. **分阶段实施**：
   - 第一阶段：数据库变更 + 后端API（保持前端不变）
   - 第二阶段：前端视图更新
   - 第三阶段：开放用户创建功能

2. **灰度发布**：
   - 先对内部用户开放工具创建
   - 收集反馈后再全量开放

3. **监控告警**：
   - 新增审核队列监控
   - 用户工具创建量监控
   - 审核响应时间监控

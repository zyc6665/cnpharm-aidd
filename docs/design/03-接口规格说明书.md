## 1. 概述

### 1.1 接口风格

- **架构风格**: RESTful API
- **数据格式**: JSON
- **字符编码**: UTF-8
- **传输协议**: HTTPS
- **API版本**: v1

### 1.2 版本管理

**URL版本化**：
```
https://api.example.com/api/v1/users
https://api.example.com/api/v2/users  (未来版本)
```

**向后兼容**：
- v1版本至少维护12个月
- 废弃接口提前3个月通知
- 响应头包含 `X-API-Version: v1`

### 1.3 认证机制

**JWT Bearer Token**：
```
Authorization: Bearer <access_token>
```

**游客模式**：
```
X-Guest-Session: <guest_session_id>
```

**管理员操作**：
- 需要JWT Token
- 用户角色必须为 `admin`

## 2. 通用规范

### 2.1 请求格式

#### 2.1.1 请求头

| Header | 必填 | 说明 | 示例 |
|--------|------|------|------|
| Content-Type | 是 | 内容类型 | `application/json` |
| Authorization | 否 | 认证令牌 | `Bearer <token>` |
| X-Guest-Session | 否 | 游客会话ID | `uuid` |
| X-Request-ID | 否 | 请求追踪ID | `uuid` |
| Accept-Language | 否 | 语言偏好 | `zh-CN,en-US` |

#### 2.1.2 请求示例

**GET请求（查询参数）**：
```bash
curl -X GET "https://api.example.com/api/v1/tools?page=1&page_size=20" \
  -H "Authorization: Bearer <token>"
```

**POST请求（JSON Body）**：
```bash
curl -X POST "https://api.example.com/api/v1/tasks" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "tool_version_id": "uuid",
    "params": {"key": "value"}
  }'
```

**文件上传（Multipart）**：
```bash
curl -X POST "https://api.example.com/api/v1/files/upload" \
  -H "Authorization: Bearer <token>" \
  -F "file=@/path/to/file.pdb" \
  -F "expires_in_sec=86400"
```

### 2.2 响应格式

#### 2.2.1 成功响应

**200 OK**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": "uuid",
    "name": "example"
  },
  "request_id": "uuid"
}
```

**201 Created**：
```json
{
  "code": 201,
  "message": "created",
  "data": {
    "id": "uuid",
    "name": "example"
  },
  "request_id": "uuid"
}
```

**204 No Content**：
```
HTTP/1.1 204 No Content
```

#### 2.2.2 错误响应

**通用格式**：
```json
{
  "code": 40001,
  "message": "Validation error",
  "details": {
    "field": "email",
    "issue": "Invalid email format"
  },
  "request_id": "uuid"
}
```

#### 2.2.3 分页格式

**请求参数**：
```
GET /api/v1/tools?page=1&page_size=20
```

**响应格式**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "items": [...],
    "meta": {
      "page": 1,
      "page_size": 20,
      "total": 135,
      "total_pages": 7
    }
  },
  "request_id": "uuid"
}
```

### 2.3 通用查询参数

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| page | integer | 页码（从1开始） | `page=1` |
| page_size | integer | 每页数量（1-200） | `page_size=20` |
| sort | string | 排序字段 | `sort=created_at` |
| order | string | 排序方向（asc/desc） | `order=desc` |
| fields | string | 返回字段（逗号分隔） | `fields=id,name` |

### 2.4 HTTP状态码

| 状态码 | 说明 | 使用场景 |
|--------|------|----------|
| 200 | OK | 请求成功 |
| 201 | Created | 资源创建成功 |
| 204 | No Content | 操作成功，无返回内容 |
| 400 | Bad Request | 请求参数错误 |
| 401 | Unauthorized | 未认证 |
| 403 | Forbidden | 无权限 |
| 404 | Not Found | 资源不存在 |
| 409 | Conflict | 资源冲突 |
| 422 | Unprocessable Entity | 业务逻辑错误 |
| 429 | Too Many Requests | 请求过于频繁 |
| 500 | Internal Server Error | 服务器内部错误 |
| 503 | Service Unavailable | 服务暂时不可用 |

## 3. 认证授权接口

### 3.1 用户注册

**接口**: `POST /api/v1/auth/register`

**权限**: 无需认证

**请求参数**:
```json
{
  "email": "user@example.com",
  "password": "Password@123",
  "display_name": "张三",
  "verification_code": "123456"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| email | string | 是 | 邮箱地址 |
| password | string | 是 | 密码（6-100位） |
| display_name | string | 否 | 显示名称（1-100字符） |
| **[v1.2新增]** verification_code | string | 是 | 邮箱验证码（6位数字） |

**响应示例**:
```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "user": {
      "id": "uuid",
      "email": "user@example.com",
      "display_name": "张三",
      "role": "user",
      "status": "active"
    },
    "access_token": "eyJhbGc...",
    "refresh_token": "eyJhbGc...",
    "token_type": "bearer"
  },
  "request_id": "uuid"
}
```

**错误码**:
- `40001`: 参数验证失败
- `40901`: 邮箱已存在
- `40010`: 验证码无效或已过期

## 4. 验证码接口 - [v1.2新增]

### 4.1 发送验证码

**接口**: `POST /api/v1/verification/send-code`

**权限**: 无需认证

**请求参数**:
```json
{
  "email": "user@example.com",
  "purpose": "register"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| email | string | 是 | 邮箱地址 |
| purpose | string | 是 | 用途：register（注册）/ reset_password（重置密码） |

**响应示例**:
```json
{
  "code": 200,
  "message": "验证码已发送",
  "data": {
    "expires_in": 300
  },
  "request_id": "uuid"
}
```

**错误码**:
- `40001`: 参数验证失败
- `40901`: 邮箱已存在（purpose=register时）
- `40401`: 用户不存在（purpose=reset_password时）
- `42901`: 发送过于频繁，请稍后再试

**业务规则**:
- 验证码有效期：5分钟
- 同一邮箱同一用途：60秒内不可重复发送
- 每日发送上限：10次/邮箱

---

### 4.2 验证验证码

**接口**: `POST /api/v1/verification/verify`

**权限**: 无需认证

**请求参数**:
```json
{
  "email": "user@example.com",
  "code": "123456",
  "purpose": "register"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| email | string | 是 | 邮箱地址 |
| code | string | 是 | 验证码（6位数字） |
| purpose | string | 是 | 用途：register / reset_password |

**响应示例**:
```json
{
  "code": 200,
  "message": "验证成功",
  "data": {
    "valid": true
  },
  "request_id": "uuid"
}
```

**错误码**:
- `40010`: 验证码无效或已过期
- `40011`: 验证码错误次数过多，请重新获取

**业务规则**:
- 最大验证尝试次数：5次
- 验证成功后验证码失效

## 12. 错误码定义

### 12.1 错误码体系

**格式**: `XYZNN`
- `X`: 错误类别（1-5）
- `Y`: 子类别（0-9）
- `Z`: 具体错误（0-9）
- `NN`: 序号（00-99）

### 12.2 系统级错误（1xxxx）

| 错误码 | HTTP状态 | 说明 |
|--------|---------|------|
| 10001 | 500 | 内部服务器错误 |
| 10002 | 503 | 服务暂时不可用 |
| 10003 | 500 | 数据库连接失败 |
| 10004 | 500 | 缓存服务异常 |
| 10005 | 500 | 对象存储异常 |

### 12.3 认证授权错误（2xxxx）

| 错误码 | HTTP状态 | 说明 |
|--------|---------|------|
| 20001 | 401 | 未提供认证令牌 |
| 20002 | 401 | 认证令牌无效 |
| 20003 | 401 | 认证令牌已过期 |
| 20004 | 403 | 权限不足 |
| 20005 | 401 | 邮箱或密码错误 |
| 20006 | 403 | 账户已被禁用 |
| 20007 | 401 | 游客会话无效或过期 |

### 12.4 请求参数错误（3xxxx）

| 错误码 | HTTP状态 | 说明 |
|--------|---------|------|
| 30001 | 400 | 请求参数缺失 |
| 30002 | 400 | 请求参数格式错误 |
| 30003 | 400 | 请求参数值无效 |
| 30004 | 400 | 文件类型不支持 |
| 30005 | 400 | 文件大小超出限制 |

### 12.5 资源错误（4xxxx）

| 错误码 | HTTP状态 | 说明 |
|--------|---------|------|
| 40001 | 404 | 资源不存在 |
| 40002 | 409 | 资源已存在 |
| 40003 | 409 | 资源状态冲突 |
| 40004 | 403 | 无权访问此资源 |

### 12.6 业务逻辑错误（5xxxx）

| 错误码 | HTTP状态 | 说明 |
|--------|---------|------|
| 50001 | 422 | 超出每日任务配额 |
| 50002 | 422 | GPU资源不足 |
| 50003 | 422 | 任务状态不允许此操作 |
| 50004 | 422 | 工具版本配置错误 |
| 50005 | 422 | 输入参数不符合schema |
| 50006 | 429 | 请求过于频繁 |
| **[v1.1新增]** 50010 | 422 | 工具配置不完整，无法提交审核 |
| **[v1.1新增]** 50011 | 422 | 当前审核状态不允许此操作 |
| **[v1.1新增]** 50012 | 422 | 该工具无需审核（平台官方工具） |
| **[v1.1新增]** 50013 | 422 | 工具不在待审核状态 |
| **[v1.1新增]** 50014 | 422 | 用户工具需审核通过后才能公开 |

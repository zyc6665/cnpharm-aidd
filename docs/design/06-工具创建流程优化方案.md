## 1. 概述

### 1.1 背景

当前平台的工具创建功能存在以下问题：

1. **创建流程不完整**：前端Create.vue仅包含基本信息表单，缺少版本配置和参数Schema编辑
2. **缺少步骤引导**：用户需要在创建工具后再手动添加版本，流程不连贯
3. **参数配置体验差**：缺少可视化的JSON Schema编辑器
4. **缺少示例功能**：无法快速加载示例配置

### 1.2 优化目标

参考SciMiner平台的工具创建流程，实现：

1. **分步骤创建向导**：基本信息 → 版本配置 → 预览提交
2. **可视化参数编辑**：JSON Schema可视化编辑器
3. **示例参数加载**：支持示例参数配置
4. **创建与版本一体化**：工具创建时同步创建初始版本

## 4. 优化方案设计

### 4.1 工具创建流程优化

#### 4.1.1 三步骤创建向导

```
┌─────────────────────────────────────────────────────────────┐
│  步骤指示器: ① 基本信息 ──→ ② 版本配置 ──→ ③ 预览提交      │
└─────────────────────────────────────────────────────────────┘

步骤1: 基本信息
├── 工具名称 * (name)
├── 工具标识 * (slug) - 自动生成建议
├── 工具描述 (description) - 支持Markdown
├── 工具分类 (category) - 下拉选择
├── 工具标签 (tags) - 多选
├── 图标设置
│   ├── Emoji图标 (icon)
│   └── 图标URL (icon_url)
└── [下一步]

步骤2: 版本配置
├── 版本号 * (version) - 默认 "1.0.0"
├── 服务类型 * (type)
│   ├── ○ 远程API (remote_api)
│   ├── ○ Docker镜像 (docker_image)
│   └── ○ Python脚本 (python_script)
├── 服务配置（根据类型显示不同字段）
│   ├── [remote_api] endpoint, method, headers
│   ├── [docker_image] image, command
│   └── [python_script] script_path
├── 运行配置
│   ├── GPU需求 (gpu_required)
│   ├── GPU显存 (gpu_memory_mb)
│   └── 超时时间 (timeout_sec)
├── 输入参数Schema * (input_schema)
│   └── [可视化编辑器] / [JSON编辑器]
├── 输出参数Schema (output_schema)
├── 示例参数 (example_params) - 新增
└── [上一步] [下一步]

步骤3: 预览与提交
├── 配置预览（只读展示）
├── 测试运行（可选）
├── 是否公开 (is_public)
└── [上一步] [保存草稿] [提交审核]
```

#### 4.1.2 参数Schema可视化编辑器

**编辑器功能**：
1. **可视化模式**：表单化添加/编辑参数字段
2. **JSON模式**：直接编辑JSON Schema
3. **模式切换**：两种模式可互相转换

**可视化模式字段**：
```
参数列表
├── [+ 添加参数]
└── 参数项
    ├── 参数名称 (name) *
    ├── 显示名称 (title)
    ├── 参数类型 (type): string/number/integer/boolean/array/object/file
    ├── 是否必填 (required)
    ├── 默认值 (default)
    ├── 描述说明 (description)
    ├── 验证规则
    │   ├── [string] minLength, maxLength, pattern, enum
    │   ├── [number/integer] minimum, maximum
    │   └── [array] minItems, maxItems
    └── [删除] [上移] [下移]
```

### 4.2 工具详情页优化

#### 4.2.1 参数表单渲染

### 6.2 创建工具接口增强

**文件**: `backend/app/api/v1/tools.py`

**变更内容**：在`create_tool`函数中处理`initial_version`字段

```python
@router.post("", response_model=dict)
async def create_tool(
    tool_data: ToolCreate,
    current_user: User = Depends(get_current_user),
    db: AsyncSession = Depends(get_db)
):
    """创建工具（支持同时创建初始版本）"""
    # ... 现有逻辑 ...

    # 创建工具
    tool = Tool(...)
    db.add(tool)
    await db.flush()  # 获取tool.id

    # === 新增：处理初始版本 ===
    if tool_data.initial_version:
        version = ToolVersion(
            tool_id=tool.id,
            version=tool_data.initial_version.version,
            changelog=tool_data.initial_version.changelog,
            notes=tool_data.initial_version.notes,
            config=tool_data.initial_version.config,
            is_active=tool_data.initial_version.is_active
        )
        db.add(version)
        await db.flush()

        # 设置为当前版本
        if tool_data.initial_version.is_active:
            tool.current_version_id = version.id
    # === 新增结束 ===

    await db.commit()
    await db.refresh(tool)

    return success_response(data=..., message="工具创建成功")
```

### 6.3 Schema验证增强

**文件**: `backend/app/schemas/tools.py`

**变更内容**：增强ToolVersionCreate的config验证

```python
from pydantic import BaseModel, Field, field_validator
import json

class ToolVersionCreate(BaseModel):
    """创建工具版本"""
    version: str = Field(..., max_length=50, description="版本号")
    changelog: Optional[str] = Field(None, description="版本更新日志")
    notes: Optional[str] = Field(None, description="版本说明")
    config: Dict[str, Any] = Field(..., description="工具配置")
    is_active: bool = Field(default=True, description="是否激活")

    @field_validator('config')
    @classmethod
    def validate_config(cls, v):
        """验证config结构"""
        required_fields = ['type']
        for field in required_fields:
            if field not in v:
                raise ValueError(f'config缺少必填字段: {field}')

        valid_types = ['remote_api', 'docker_image', 'python_script']
        if v.get('type') not in valid_types:
            raise ValueError(f'type必须是以下之一: {valid_types}')

        # 验证input_schema是否为有效JSON Schema
        if 'input_schema' in v:
            schema = v['input_schema']
            if not isinstance(schema, dict):
                raise ValueError('input_schema必须是有效的JSON Schema对象')
            if schema.get('type') != 'object':
                raise ValueError('input_schema的type必须为object')

        return v
```

interface SchemaField {
  name: string              // 字段名
  title: string             // 显示名称
  type: FieldType           // 字段类型
  required: boolean         // 是否必填
  description: string       // 描述说明

  // 类型特定选项
  stringOptions?: {
    minLength?: number
    maxLength?: number
    pattern?: string
    format?: 'email' | 'uri' | 'date' | 'file'
    enum?: string[]         // 枚举值
  }

  numberOptions?: {
    minimum?: number
    maximum?: number
    multipleOf?: number
  }

  arrayOptions?: {
    items: SchemaField      // 数组项类型
    minItems?: number
    maxItems?: number
  }

  objectOptions?: {
    properties: SchemaField[]  // 嵌套字段
  }
}

type FieldType = 'string' | 'number' | 'integer' | 'boolean' | 'array' | 'object' | 'file'

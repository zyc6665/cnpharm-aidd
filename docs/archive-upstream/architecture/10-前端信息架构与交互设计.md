# 前端信息架构与交互设计

> 修订日期：2026-09-05。本次补充科学结果、候选决策和实验反馈交互；V1 先展示模型卡/科学附件和基础结果，V1.1 才实现结构化候选决策与实验导入，V2 才实现多轮 DesignCycle 复盘。

## 1. 目标

前端目标是让药物研发人员以“拖节点、连线、补必要输入、查看结果”的方式完成研发流程，而不是理解平台内部的 file_id、ArtifactVersion、legacy 参数字段和执行器差异。

第一版重点：

- 工作流画布占据主屏，不随节点位置改变可视区域大小。
- 工具库、运行配置、结果中心是可折叠侧边栏。
- 节点是工作面板，不只是小方块。
- 节点可独立运行，可上传文件或自动使用上游产物。
- 可视化可以在节点内预览，也可以放大查看，且不与画布拖拽和缩放冲突。

## 2. 信息架构

```text
平台首页
  ├─ 项目空间
  │   ├─ 项目概览
  │   ├─ Artifact 资产
  │   ├─ 候选决策
  │   ├─ 实验反馈
  │   ├─ DesignCycle 复盘
  │   ├─ 工作流
  │   ├─ 任务中心
  │   └─ 智能体
  ├─ 工具中心
  │   ├─ 工具库
  │   ├─ 工具详情
  │   └─ 工具运行
  ├─ 工作台
  │   ├─ 画布
  │   ├─ 工具库侧栏
  │   ├─ 节点配置侧栏
  │   └─ 结果中心侧栏
  └─ 管理后台
      ├─ 工具管理
      ├─ 模型卡与验证证据
      ├─ 标签管理
      ├─ 执行资源
      └─ 用户与权限
```

Project 是研发资产上下文，但工具中心仍允许独立运行。无项目运行的标准输出进入用户默认工作空间。

## 3. 工作流工作台布局

### 3.1 主布局

```text
┌────────────────────────────────────────────────────────────┐
│ 顶部栏：流程名 / 保存 / 预检 / 运行 / 状态摘要              │
├──────────────┬──────────────────────────────┬──────────────┤
│ 工具库侧栏   │ 固定视口画布                  │ 配置/结果侧栏 │
│ 可折叠/缩放  │ 节点面板 + 连线 + 缩放平移    │ 可折叠/缩放   │
└──────────────┴──────────────────────────────┴──────────────┘
```

规则：

- 画布 viewport 固定占满剩余区域。
- 节点位置只影响内部 canvas transform，不影响页面布局尺寸。
- 左右侧栏折叠时画布重新计算可用 viewport，但不改变节点世界坐标。
- 节点内可视化预览使用固定尺寸和 object-fit 策略，不推动节点无限变大。

### 3.2 侧栏策略

左侧工具库：

- 搜索。
- 动态标签筛选。
- 研发阶段筛选。
- 资源类型筛选。
- 最近使用和推荐工具。

右侧配置/结果：

- 选中节点时显示节点配置。
- 选中边时显示绑定解释。
- 无选中时显示流程级输入、预检和结果中心。
- 支持展开为宽面板查看表格或三维结构。

## 4. 工具库体验

工具库不应使用硬编码筛选条件。筛选数据来源：

- 管理员维护的工具标签。
- Tool Contract 的 `category.stage`。
- Tool Contract 的 `artifacts.inputs/outputs`。
- Resource Profile 的 CPU/GPU/长任务属性。
- 用户最近使用记录。

推荐分组：

| 分组 | 示例工具 |
| --- | --- |
| 获取数据 | Fetch PDB、Fetch PubChem |
| 数据准备 | Protein Preparation、Ligand Preparation、Conformer Generation |
| 结构分析 | LVpocket、Pocket Visualization |
| 生成设计 | Molecule Generation |
| 筛选评估 | RDKit Properties、ADMET、Toxicity、Synthetic Accessibility |
| 对接模拟 | Docking、MD |
| 打分报告 | Scoring Rerank、Report Summary |

工具卡片应展示：名称、简短用途、输入类型、输出类型、资源标签、是否可工作流运行。不要展示内部 executor 细节作为主标题。

预测、生成、打分和筛选类工具还应展示模型卡状态、证据等级、适用域策略和支持的 endpoint/score definition。缺失科学证据时显示 unknown 或未验证，不以“工具可运行”替代“科学已验证”。

## 5. 节点面板设计

节点是画布上的工作面板，建议结构：

```text
┌──────────────────────────────────────┐
│ TOOL / 状态 / 独立运行 / 更多          │
│ 工具名称                              │
├──────────────────────────────────────┤
│ 输入状态：protein 已绑定 / ligand 缺失 │
│ 参数摘要：ph 7.4 / remove water       │
├──────────────────────────────────────┤
│ 结果预览：Artifact Renderer mini view  │
├──────────────────────────────────────┤
│ 输出：protein_structure@1 / 下载 / 放大 │
└──────────────────────────────────────┘
```

节点内只展示最关键内容：

- 输入是否 ready。
- 必填参数是否完整。
- 最近一次任务状态。
- 主要输出预览。
- 独立运行按钮。

详细参数、日志、全部输出和错误解释放到右侧面板。

## 6. 节点独立运行

每个可执行工具节点必须支持独立运行：

- 有上游连接时，默认使用上游 Artifact Binding。
- 无上游连接时，显示上传文件、选择项目 Artifact 或使用示例。
- 普通参数来自 `parameters_schema` 自动表单。
- 标准输入来自 `artifacts.inputs` 自动表单。
- 运行前展示前端 Readiness Preview，提交后由后端 Run Preparation 做权威校验和运行准备。

用户不应该手动填写上游文件路径，也不应该看见 `input_bindings`、`standard_input_uploads` 这类平台内部字段。

## 7. 自动绑定交互

### 7.1 拖拽连线

当用户把上游输出连到下游节点时：

1. 前端基于 Artifact type 查找可匹配 slot。
2. 只有一个匹配时自动绑定。
3. 多个匹配时弹出 slot 选择。
4. 类型不匹配时禁止连线并解释原因。
5. role 不满足时允许连线但提示需要准备或转换。

### 7.2 工作流输入提升

如果节点必填输入没有上游来源，平台应将其提升为 Workflow Input：

- 流程级输入面板展示缺失项。
- 用户可上传文件或选择项目 Artifact。
- 运行时绑定到所有依赖该输入的节点。

### 7.3 预检文案

预检要使用研发语言：

- “LVpocket 需要蛋白结构，请连接 Fetch PDB 或上传 PDB 文件。”
- “Vina 对接需要 receptor_pdbqt，请先运行 Protein Preparation。”
- “ADMET 需要分子表，请连接分子生成或上传包含 SMILES 的表格。”
- “MD 是长时 GPU 任务，预计 4 小时，提交后可在任务中心查看。”

## 8. 可视化设计

### 8.1 Renderer 复用

Artifact Renderer 按标准 Artifact 类型复用：

| Artifact | Renderer |
| --- | --- |
| `protein_structure@1` | Protein Renderer |
| `ligand_structure@1` | Ligand Renderer |
| `binding_pocket@1` | Binding Pocket Renderer |
| `molecule_table@1` | Molecule Table Renderer |
| `run_report@1` | Run Report Renderer |

### 8.2 节点内预览

- 固定预览高度，避免节点被三维视图撑开。
- 多输出时默认展示 primary output，可切换输出 slot。
- 渲染失败时显示可操作错误，例如“登录已过期，请重新登录后刷新结果”。

### 8.3 放大查看

放大查看应使用 portal/modal 或右侧宽面板，不嵌在 canvas transform 内。

要求：

- 放大按钮固定在预览左上角。
- 按钮白底、细边框、可见焦点态。
- 放大层和画布事件隔离，避免抢占拖拽、滚轮和缩放。
- 支持多个节点同时保留 mini preview；放大层一次只聚焦一个 Artifact。

## 9. 工具详情页

工具详情页和工作流节点应共享同一套输入表单模型。

必备能力：

- 一键填入示例。
- 参数 schema 自动表单。
- 标准 Artifact 输入上传或选择。
- 无项目时允许上传文件运行，标准输出进入默认工作空间。
- 有项目时可选择项目 Artifact。
- 展示 Tool Contract、样例、资源画像和最近任务。

## 10. 保存工作流恢复

保存的工作流加载后应恢复：

- 节点工具 slug 和当前 Tool Contract。
- 节点 artifact input slots 和 outputs。
- 节点参数。
- 节点最近任务 ID。
- 节点输出 ArtifactVersion 绑定。
- 边的语义绑定结果。

如果工具契约升级，加载时应使用当前 Tool Contract hydrate 缺失槽位，并提示“工具契约已更新，请重新预检”。

## 11. 科学结果、候选决策与实验反馈

### 11.1 版本边界

| 版本 | 前端能力 | 不展示为已完成 |
| --- | --- | --- |
| V1 | 基础 ADMET 结果、模型卡/科学附件入口、endpoint/单位/模型版本展示、候选导出 | 多模型质量看板、实验摘要导入、自动科学门禁 |
| V1.1 | CandidateSet、CandidateDecision、受控实验导入、预测-实测比较、科学质量看板 | 多轮自动闭环、自动再训练、ELN/LIMS 替代 |
| V2 | DesignCycle 轮次页、外部实验系统引用、相似/聚类、对接/MD 结果复盘 | 无人工审批的自动实验执行 |

### 11.2 候选表格

候选表格应按科学语义分栏，避免把不同来源的数值混为一个排名表：

| 分组 | 典型列 | 交互要求 |
| --- | --- | --- |
| 身份 | source_row_id、molecule_id、structure_state_id、canonical_smiles | 支持查看结构状态和去重原因 |
| 预测 | endpoint、value、unit/label、model_version、applicability_status | OOD、failed、not_tested 与 null 单独显示 |
| 评分 | score_name、raw_value、normalized_value、direction、score_definition | 不同协议默认不可直接排序 |
| 实测 | measured_value、unit、qualifier、protocol、compound_batch | 删失值、重复值和不同批次可展开 |
| 证据 | model_card、evidence_level、verification_ref、limitations | 点击查看模型卡和验证记录 |
| 决策 | select/exclude/hold、reason、reviewer、snapshot_time | 决策保存后形成不可变快照 |

表格过滤和排序必须尊重 `score_definition`；当单位、endpoint、protocol 或 preparation profile 不可比时，排序按钮应提示原因并要求用户选择可比子集。

### 11.3 候选决策快照

CandidateDecision 页面应支持：

- 从固定 CandidateSet 版本创建选择、排除和待复核记录。
- 记录阈值、排序规则、人工理由、操作者、时间和关联报告。
- 导出与快照完全一致的候选清单，不受后续模型重跑或表格过滤影响。
- 重开或更正时生成新版本，并保留 supersedes 关系。

### 11.4 实验导入预览

实验反馈入口只接受受控 CSV/JSON 摘要。导入前必须展示预览：

- 字段映射、endpoint、单位、protocol、qualifier 和 batch 识别结果。
- 可接受行、拒绝行、重复行、无法关联 molecule/state 的行及原因。
- 单位转换和删失值处理规则。
- 确认后生成新的 `assay_result@1` ArtifactVersion 和导入报告。

全无效导入不应静默成功；应生成导入报告或错误摘要供用户修正。

### 11.5 预测-实测对齐

预测-实测比较页必须展示配对规则版本、可比性判断和排除原因。只有 molecule/state、endpoint、单位、protocol 和 qualifier 规则均满足时，才计算普通误差或相关性指标；其余记录可展示但不能参与默认统计。

### 11.6 状态表达

| 状态 | 展示文案 | 行为 |
| --- | --- | --- |
| `unknown` | 科学信息未知 | 可下载，不参与需要该字段的比较 |
| `out_of_domain` | 超出适用域 | 可展示，排序和结论需显式确认 |
| `failed` | 预测或导入失败 | 保留失败分母和原因 |
| `not_comparable` | 不可比较 | 禁止默认误差计算或综合分 |
| `censored` | 删失/区间值 | 保留 qualifier，不当作精确值 |

## 12. 错误和空状态

| 场景 | 展示策略 |
| --- | --- |
| 工具契约不可执行 | 说明缺失 contract、被禁用或校验失败，并给管理员入口 |
| 节点缺输入 | 在节点和右侧面板同时显示缺失 slot |
| 上游未完成 | 显示等待上游，不允许误报类型错误 |
| 渲染失败 | 显示文件权限、格式或登录原因 |
| 保存工作流无任务 | 显示“尚未运行”，而不是空白节点 |
| 长任务运行中 | 展示进度、日志入口、取消按钮和任务中心链接 |
| 科学证据未知 | 显示 unknown、模型卡缺失或验证范围不匹配 |
| 候选值不可比 | 标出 endpoint、单位、protocol 或 score definition 差异 |
| 实验导入全无效 | 展示拒绝原因和字段映射问题，不生成可用 AssayResult |

## 13. 管理后台联动

管理员可维护：

- 工具标签。
- 工具分组。
- Tool Contract 校验状态。
- 示例输入。
- 是否进入工具库、工作流和智能体。
- 资源画像和执行器配置。
- 模型卡、验证记录、endpoint、score definition 和 scientific profile 发布状态。

前端筛选和展示应读取这些配置，不能把标签写死在组件中。

## 14. 验收标准

- 用户能在 5 分钟内完成 Fetch PDB -> Protein Preparation -> LVpocket 的连线和运行。
- 用户不需要手动绑定文件路径或填写 Artifact 内部 ID。
- 新工具只要 Tool Contract 合法，就能出现在工具库和工作流节点库。
- 节点独立运行、工具详情页运行、全流程运行的输入逻辑一致。
- 结构、配体、口袋和表格结果都能在节点内预览并放大查看。
- V1 基础 ADMET 结果能展示 endpoint、单位或标签、模型版本、证据等级和模型卡入口。
- V1.1 候选决策、实验导入预览和预测-实测对齐能清楚区分预测、评分、实测和不可比状态。

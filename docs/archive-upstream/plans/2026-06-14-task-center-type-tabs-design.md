# Task Center Type Tabs Design

## Goal

任务中心在现有状态标签「全部 / 运行中 / 历史」之外，新增内容类型标签，避免智能体会话卡片和独立工具任务混排导致列表杂乱。

## Design

在任务中心筛选栏下方新增一个紧凑的二级 segmented 控件，包含：

- 全部类型
- 智能体任务
- 独立工具任务

状态标签继续表示任务状态范围，类型标签只表示内容来源。两个维度叠加生效：例如「运行中 + 智能体任务」只显示运行中的 agent 会话；「历史 + 独立工具任务」只显示已结束的普通工具任务。

## Rendering

「全部类型」不再把两类卡片直接混排，而是按区块展示：

- 智能体任务区：渲染 agent 会话卡片，默认折叠。
- 独立工具任务区：渲染普通工具任务卡片。

当切到单一类型时只显示对应区块，不显示另一个区块标题。空状态沿用当前任务中心空态。

## Data Flow

继续使用现有 `/tasks` 和 `/agents/aidd/runs` 数据。前端用 agent run steps 的 `task_id` 收集 agent 子任务 ID，从普通任务列表中过滤这些子任务。

## Testing

新增前端单元测试覆盖：

- 类型标签 helper 的显示策略。
- 列表页接入类型 segmented 控件。
- 列表页按类型条件渲染 agent 区块和独立任务区块。

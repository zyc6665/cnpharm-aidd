# 首页 CPUPDB 导航与 AIDD 流程设计

**日期：** 2026-05-26

**目标：** 在不新增真实后端路由的前提下，为首页补上 `cpupdb` 数据库占位入口，并将原“应用场景”区块改造成按 AIDD 顺序展示的平台功能流程。

## 现状

- 顶部导航位于 `frontend/src/components/layout/DefaultLayout.vue`
- 首页位于 `frontend/src/views/home/index.vue`
- 首页当前第二屏为“应用场景”，采用 4 个并列卡片
- 文案由 `frontend/src/locales/zh-CN/index.ts` 与 `frontend/src/locales/en-US/index.ts` 提供

## 设计决策

### 1. `cpupdb` 入口

- 在顶部导航新增一个外链菜单项，名称为 `CPUPDB`
- 链接使用 `https://www.cpupdb.com`
- 链接通过组件内常量维护，后续替换只改一处

### 2. 首页第二屏改造

- 将区块标题从“应用场景”调整为“平台功能”
- 将区块内容改为 AIDD 顺序流：
  1. 口袋探索
  2. 分子生成或虚拟筛选
  3. 分子对接及结合亲和力预测
  4. 性质预测
  5. 先导化合物优化
- 每一步使用独立卡片展示，并在相邻步骤间加入箭头

### 3. 响应式策略

- 桌面端：横向流程展示，箭头位于卡片之间
- 移动端：改为纵向堆叠，隐藏横向箭头，保持流程顺序可读

### 4. 实施约束

- 不新增站内路由
- 不引入新的状态管理或配置模块
- 不修改首页其他 CTA 与功能卡片

## 测试策略

- 增加前端源码测试，锁定以下结果：
  - 导航中存在 `CPUPDB` 占位入口
  - 首页存在“平台功能”标题
  - 首页源码中包含 AIDD 五步顺序与箭头展示实现
  - 中英文 locale 均具备对应文案

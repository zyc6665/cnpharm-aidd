## 1. 产品定位

面向中国医药本部药物研发人员的 **AI 药物研发统一工作环境**。以「研发项目」和「靶点」为主线，把分散的化合物数据、蛋白结构与序列、活性与性质数据、文献、实验数据和计算结果集中管理，并串接靶点分析 → 分子/多肽设计 → 性质预测 → 虚拟筛选 → 计算评估的研发链路，形成可复用、可追溯的研发流程。

**一句话定位**：一个围绕项目与靶点组织数据、用工作流调度国产算力、每一次计算结果都可回溯的 AI 药物研发工作台。

## 2. 用户角色与画像

| 角色 | 代号 | 主要诉求 | 高频操作 |
|---|---|---|---|
| 药物研发科学家 | RES | 快速获得候选物并判断优先级 | 建项目、导靶点、发起设计、看结果比对 |
| 计算化学家 / CADD | CADD | 精细控制算法参数、跑批量计算 | 参数配置、批量筛选、MD/自由能计算、导出结构 |
| 项目负责人 | PL | 掌握项目进度与资产沉淀 | 项目总览、成员协作、任务状态监控、报告导出 |
| 系统管理员 | ADMIN | 算力、模型、工具、用户与备份 | 用户权限、模型与工具注册、算力队列、备份恢复 |

**规模假设**：不少于 10 名用户同时开展常规业务操作（规范书硬指标）；计算任务并发受 16 张 DCU 限制，需排队。

## 3. 术语表

| 术语 | 说明 |
|---|---|
| 靶点（Target） | 具有药物作用的生物大分子，本项目以蛋白质为主 |
| 结合口袋（Pocket） | 蛋白表面可供配体结合的凹陷区域，由算法预测并按评分排序 |
| 候选物（Candidate） | 设计或筛选生成的候选小分子或多肽 |
| 候选集合（Candidate Set） | 归属于某项目的一批候选物及其属性与预测结果 |
| 计算任务（Task） | 一次模型推理或分子计算的执行实例，含输入、参数、环境、产物 |
| 工作流（Workflow） | 将多个计算任务按研发顺序编排的可复用执行模板 |
| 研发资产 | 项目内沉淀的数据集、模型、工作流模板、候选集合、结果报告 |
| DCU | 海光深度计算单元（Deep Computing Unit），本项目算力硬件 |
| 追溯三元组 | 任一结果可回溯的「输入数据 + 模型/工具版本 + 运行参数」 |

## 5. M1 研发项目与数据管理

> 平台应提供统一的研发项目管理与数据归集能力，支持按照研发项目建立独立的项目空间，集中管理项目相关的靶点信息、候选化合物及其他研发资料。

### 5.1 功能清单

| 编号 | 功能点 | 优先级 |
|---|---|---|
| DRP-M1-FR-01 | 项目空间创建与管理（名称、描述、靶点关联、成员、状态） | P0 |
| DRP-M1-FR-02 | 项目内成员与角色协作（负责人/成员/只读） | P0 |
| DRP-M1-FR-03 | 化合物结构文件导入与展示（单个/批量） | P0 |
| DRP-M1-FR-04 | 蛋白质序列导入与展示 | P0 |
| DRP-M1-FR-05 | 蛋白质结构文件导入与展示 | P0 |
| DRP-M1-FR-06 | 批量研发数据导入（分子结构文件 + 表格文件） | P0 |
| DRP-M1-FR-07 | 研发数据导出 | P0 |
| DRP-M1-FR-08 | 数据来源与版本信息记录 | P1 |
| DRP-M1-FR-09 | 数据更新历史查看 | P1 |

### 5.2 关键功能详述

#### DRP-M1-FR-01 项目空间

- **输入**：项目名称、描述、关联靶点、负责人、成员列表、项目状态（进行中/暂停/归档）
- **输出**：项目空间实例
- **业务规则**
  - BR-1：项目为一切研发数据的归属容器，靶点、候选物、任务、结果必须归属于某一项目
  - BR-2：项目归档后只读，不可再提交计算任务
  - BR-3：项目删除为软删除，保留 90 天后物理清理（含对象存储文件）
- **验收标准（AC）**
  - AC-1：创建项目 ≤ 3 步操作完成，页面响应 ≤ 3 秒
  - AC-2：项目详情页可按 Tab 查看 靶点 / 候选物 / 数据集 / 任务 / 结果 五个维度
  - AC-3：非成员不可见该项目任何数据与结果

#### DRP-M1-FR-03 化合物结构导入与展示

- **支持格式**：`.smi`/`.csv`（SMILES）、`.sdf`、`.mol`、`.mol2`；单个文件 ≤ 200MB
- **展示**：二维结构式渲染、分子式、分子量、SMILES、InChI、基础理化属性（由 RDKit 计算）
- **业务规则**
  - BR-1：同一项目内化合物以 InChIKey 去重，重复导入提示「已存在，是否更新」
  - BR-2：SMILES 解析失败的记录进入「导入异常清单」，可下载修正后重传，不阻断整批
  - BR-3：每次导入生成一条数据版本记录
- **验收标准**
  - AC-1：导入 1000 条 SMILES 的 CSV，成功率 ≥ 99%，失败项可定位到行号
  - AC-2：列表页可渲染二维结构缩略图，点击查看详情

#### DRP-M1-FR-06 批量导入

- **支持**：分子结构文件（SDF/SMILES/MOL2）与表格文件（CSV/XLSX）
- **业务规则**
  - BR-1：支持字段映射（表格列名 → 系统字段），映射模板可保存复用
  - BR-2：批量导入为异步任务，提供进度与结果汇总（成功 N 条 / 失败 M 条）
  - BR-3：单批上限 10 万条记录，超出需分批
- **验收标准**：导入过程不阻塞页面操作；中断后可续传/重传

#### DRP-M1-FR-08/09 数据版本与追溯

- **记录内容**：来源类型（导入/计算生成/外部录入）、来源文件、导入人、导入时间、版本号、变更摘要
- **验收标准**：任一化合物/蛋白可查看其版本列表与前后差异（属性级 diff）

## 6. M2 AI 靶点结构分析 ★

> 以用户导入的蛋白质序列或已有蛋白质结构为输入，完成结构获取、结构准备和结合位点分析，为后续小分子及多肽设计提供结构基础。

### 6.1 功能清单

| 编号 | 功能点 | ★ | 优先级 |
|---|---|---|---|
| DRP-M2-FR-01 | 蛋白质序列输入与管理 | | P0 |
| DRP-M2-FR-02 | 蛋白质三维结构预测（序列 → 结构） | ★ | P0 |
| DRP-M2-FR-03 | 已有蛋白质结构导入 | | P0 |
| DRP-M2-FR-04 | 结构准备（去水、加氢、加电荷、质子化、修复缺失残基） | | P0 |
| DRP-M2-FR-05 | 生成计算可用的结构文件（PDB/PDBQT） | | P0 |
| DRP-M2-FR-06 | 结合口袋预测与评分排序 | ★ | P0 |
| DRP-M2-FR-07 | 关键残基识别与空间位置展示 | ★ | P0 |
| DRP-M2-FR-08 | 蛋白整体结构与口袋三维可视化 | | P0 |
| DRP-M2-FR-09 | 结构、位点及分析结果导出 | | P1 |

### 6.2 关键功能详述

#### DRP-M2-FR-02 蛋白质三维结构预测 ★

- **输入**：蛋白质氨基酸序列（FASTA/手工粘贴）、预测参数（模型、max recycle、是否 relax）
- **输出**：预测三维结构（PDB）、置信度指标（pLDDT / PAE）、预测报告
- **业务规则**
  - BR-1：序列长度上限建议 1500 aa，超出需评估显存与时间（属长时任务）
  - BR-2：预测任务为异步长时任务，支持进度与日志查看
  - BR-3：预测结果与输入序列、模型名称及版本强绑定存档
- **验收标准**
  - AC-1：输入 ≤ 400 aa 的序列，可在合理时间内产出 PDB 结构并在 3D 视图中渲染
  - AC-2：结果页展示平均 pLDDT 与逐残基置信度着色
  - AC-3：预测结构可一键进入结构准备流程

> **技术风险登记（R-02）**：结构预测的选型已确定为 **Boltz-2**（2026-08 实测：8 卡并发 3 轮 24/24 通过，238 aa 单任务 wall p50 123s）。AlphaFold 2.3.2 在 DCU 上输出 NaN，**不作为交付路径**，仅保留 CPU 版兜底。当前阻塞点是测试机已回收、模型未资产化，见 `08-DCU适配复现与验证计划`。

#### DRP-M2-FR-06 结合口袋预测 ★

- **输入**：蛋白质结构（PDB）
- **输出**：候选口袋列表（中心坐标、体积、评分、排序）、口袋残基组成
- **业务规则**
  - BR-1：至少输出 Top-N（默认 5）口袋并按评分降序排列
  - BR-2：口袋可命名、可标记为「选定口袋」，选定后作为分子设计与对接的约束输入
  - BR-3：口袋定义可持久化复用（避免下游重复计算）
- **验收标准**
  - AC-1：口袋列表含 评分 / 体积 / 中心坐标 / 残基数 四要素
  - AC-2：口袋在 3D 视图中以半透明体积渲染，可与蛋白结构叠加显示

#### DRP-M2-FR-07 关键残基识别 ★

- **输出**：口袋周边关键残基列表（残基编号、氨基酸、链、空间位置）
- **验收标准**：点击残基可在 3D 视图中高亮定位并居中

## 7. M3 AI 分子与多肽设计 ★

> 基于靶点信息开展小分子设计；根据靶点信息与设定条件开展多肽设计。

### 7.1 功能清单

| 编号 | 功能点 | ★ | 优先级 |
|---|---|---|---|
| DRP-M3-FR-01 | 基于靶点/口袋的小分子 AI 设计（生成候选分子） | ★ | P0 |
| DRP-M3-FR-02 | 基于靶点信息与设计条件的多肽设计（生成候选序列） | ★ | P0 |
| DRP-M3-FR-03 | 预置分子设计模型选择与模型管理能力 | | P0 |
| DRP-M3-FR-04 | 候选物保存至项目候选集合 | | P0 |
| DRP-M3-FR-05 | 候选物详情查看（结构/序列 + 属性） | | P0 |
| DRP-M3-FR-06 | 按设计条件或分子属性筛选 | | P1 |
| DRP-M3-FR-07 | 按模型评分或指定属性排序 | | P1 |
| DRP-M3-FR-08 | 多候选物结构与分析结果比较 | | P1 |

### 7.2 关键功能详述

#### DRP-M3-FR-01 小分子 AI 设计 ★

- **输入**：靶点结构、选定口袋、生成数量、可选约束（分子量区间、logP 区间、骨架/片段、是否含特定子结构）
- **输出**：候选分子集合（SMILES/SDF + 生成模型评分）
- **业务规则**
  - BR-1：单次生成数量上限 1000（可配置），超量分批提交
  - BR-2：生成结果需经合法性校验（SMILES 可解析、价键合理），非法结构自动剔除并计数
  - BR-3：生成结果自动去重
- **验收标准**
  - AC-1：一次设计任务可产出 ≥ 100 个合法候选分子
  - AC-2：结果列表展示 二维结构、模型评分、分子量、logP、QED 等属性
  - AC-3：可全选或按条件勾选后保存至候选集合

#### DRP-M3-FR-02 多肽设计 ★

- **输入**：靶点结构/序列、多肽长度范围、设计条件（等电点、疏水比例、避免 Cys、末端修饰等）
- **输出**：候选多肽序列集合（FASTA/序列列表 + 评分）
- **验收标准**：产出序列可一键送性质预测或直接保存

#### DRP-M3-FR-08 候选物比较

- **能力**：并排比较 ≤ 6 个候选物的 结构（2D/3D）、属性、预测指标、计算结果
- **验收标准**：差异项高亮标注，比较视图可导出为图片或表格

## 8. M4 亲和力与 ADMET 性质预测 ★

> 面向候选小分子的亲和力与 ADMET 性质预测，为候选物的初步评价和筛选提供定量参考。

### 8.1 功能清单

| 编号 | 功能点 | ★ | 优先级 |
|---|---|---|---|
| DRP-M4-FR-01 | 结合目标蛋白与候选分子结构的亲和力预测评分 | ★ | P0 |
| DRP-M4-FR-02 | 候选小分子 ADMET 性质指标预测 | ★ | P0 |
| DRP-M4-FR-03 | 单个候选物提交预测任务 | | P0 |
| DRP-M4-FR-04 | 候选集合批量预测 | ★ | P0 |
| DRP-M4-FR-05 | 预测结果展示并与候选物关联 | | P0 |
| DRP-M4-FR-06 | 按性质指标筛选、排序、多候选比较 | | P1 |
| DRP-M4-FR-07 | 预测指标与结果数据导出 | | P1 |

### 8.2 关键功能详述

#### DRP-M4-FR-01 亲和力预测 ★

- **输入**：目标蛋白结构（或复合物）、候选分子结构
- **输出**：亲和力预测评分（如 pKd / pIC50 / ΔG 估计）、置信度/适用域提示
- **业务规则**
  - BR-1：预测结果标注所用模型名称与版本、输入复合物来源
  - BR-2：若输入缺少蛋白结构，需提示无法进行结构驱动的亲和力预测
- **验收标准**：结果页展示评分值、模型版本、预测时间，并可与对接结果并列查看

#### DRP-M4-FR-02 ADMET 预测 ★

- **预测指标族（建议）**：
  - 吸收：Solubility、Caco-2 渗透性、HIA、Bioavailability
  - 分布：PPB、BBB、VDss
  - 代谢：CYP 抑制/底物（1A2/2C9/2C19/2D6/3A4）
  - 排泄：Clearance、Half-life
  - 毒性：hERG、AMES、DILI、Hepatotoxicity、Skin sensitization
- **业务规则**：不同指标可由不同子模型产出，结果以「指标 → 值 + 单位 + 判定 + 模型版本」四元组呈现
- **验收标准**：单次批量预测 ≥ 500 条候选物时，任务可异步执行且提供进度

#### DRP-M4-FR-04 批量预测 ★

- **业务规则**
  - BR-1：批量任务按候选集合或勾选集合提交，支持断点重跑失败项
  - BR-2：批量任务受 DCU 队列限制，排队时可见排队序号
- **验收标准**：批量任务完成后生成汇总统计（各指标分布、达标率）

## 9. M5 虚拟筛选与计算评估 ★

> 结合分子构象、药效团特征、蛋白—配体对接结果及分子动力学等计算手段，对候选物进行结构分析和计算评价。

### 9.1 功能清单

| 编号 | 功能点 | ★ | 优先级 |
|---|---|---|---|
| DRP-M5-FR-01 | 构象分析与代表性构象展示 | | P1 |

### 9.2 关键功能详述

#### DRP-M5-FR-03 分子对接

- **输入**：受体结构（PDBQT，来自结构准备）、口袋/对接盒定义、配体结构（单个或集合）、对接参数（exhaustiveness、poses 数量、随机种子）
- **输出**：每个配体的 Top-N 结合姿势（SDF/PDBQT）、对接评分（kcal/mol）、受体—配体相互作用标注
- **业务规则**
  - BR-1：对接盒支持三种定义方式：选定口袋自动生成 / 指定残基周边 / 手工输入中心与尺寸
  - BR-2：对接任务可指定 CPU 核数并行，不占用 DCU（见架构文档算力策略）
  - BR-3：随机种子需记录，保证结果可重现
- **验收标准**：结果页可逐一查看结合姿势并在 3D 视图中叠加受体表面

#### DRP-M5-FR-04 批量虚拟筛选 ★

- **输入**：候选物集合、筛选流程配置（构象生成 → 药效团过滤 → 对接 → 重打分）
- **输出**：按计算评分排序的候选物优先级清单、每项中间结果
- **业务规则**
  - BR-1：支持设置筛选漏斗阈值（如药效团命中数 ≥ 3、对接分 ≤ -8.0），逐级过滤
  - BR-2：亿级不现实，系统设计目标为单批 ≤ 10 万条候选物（受算力约束）
  - BR-4（v1.1 新增、**v1.2 按实测核数修订**，**强约束**）：按 `03` §5.2.2 规模分层，1 万条以上属 **XL 层**，实测量级为 **天级而非小时级**。**v1.2 修订**：甲方已确认计算节点 **128 核**（`D-03-11` 已关闭），据 `03` §5.6.2 重算——10 万条候选物按 Vina 10~60s/配体为 **278~1667 CPU·h**，即 **约 3.1~18.5 小时（典型 9.3 小时）**，原按 64 核估算的「13 小时 / 2~11 个 64 核日」作废。因此：① 提交 XL 任务时平台**必须先返回预估耗时区间与预估完成时间，用户确认后才入队**（预估分母取 **90 有效核** = 128 × 0.7，不得用 128 理论值）；② **默认启用漏斗前置**（先用药效团/ADMET 粗筛掉 90% 再对接），否则不得放行；③ 配额按**算力分钟**而非任务个数计量。算力核算依据见 `03` §5.6.1~§5.6.3，部署机 32 核不参与计算见 `03` §5.6.4。
  - BR-3：批量筛选过程可中断，已完成部分结果不丢失
- **验收标准**
  - AC-1：筛选结束后产出可排序的优先级表格，支持导出
  - AC-2：每一条结果可下钻查看其对接姿势与评分构成

#### DRP-M5-FR-05/06 MD 与自由能

- **MD 输入**：复合物结构、力场、水模型、模拟时长（ns）、温度/压力、步长
- **MD 输出**：轨迹文件（xtc/trr）、能量文件、RMSD/RMSF 曲线、分析报告
- **自由能**：基于 MD 轨迹的 MM-PBSA/MM-GBSA 结合自由能估算（ΔG，kcal/mol），含能量分解项
- **业务规则**
  - BR-1：MD 属长时任务（小时级~天级），必须支持断连后状态保持与进度查询
  - BR-2：MD 结果文件较大（GB 级），走对象存储，页面只提供索引与下载
- **验收标准**：任务运行中可查看当前帧/总帧进度与实时 RMSD 曲线

## 16. 验收方式建议

1. **功能验收**：按《02-需求追踪矩阵》逐条演示，★ 条款必须现场跑通真实数据
2. **性能验收**：10 并发常规操作压测报告，≤ 3 秒达标
3. **追溯与复现验收（v1.2 修订口径）**：验收**不是**要求「每个模型复算结果都一样」——扩散/采样类模型（STD-Diff、Pocket2Mol、TheraPainter）物理上做不到。实际验收两件事：
   - **① 平台可复现能力**：按 `03` §7.4 抽检——D1 抽 1 个**必须逐字节一致**（SHA-256）；D2 抽 1 个按**该模型已标定的容差**比对（`03` §7.4.2，初值如结构 RMSD ≤ 0.5 Å、对接评分偏差 ≤ 0.5 kcal/mol）；D3 抽 1 个重复 3 次取统计量；
   - **② 如实声明**：D4（`NON_REPRODUCIBLE`）的模型必须在 `model_registry` 的 manifest 与详情页上如实标注，**不参与复现验收**，只核对声明是否与实际一致。
   - 容差初值与分组需甲方书面确认（`D-03-12`），且**最终值以 `08` 复现实测回填为准**；未标定的模型标 `PENDING`，不具备验收条件。
4. **文档验收**：第一 ~ 第四批文档齐套（编号件 00~18 共 22 份已交付，含 `03A`/`03B`/`08A` 三份补充件；`16` 用户操作手册于 2026-10-23 补交付；`18` 验收报告 v1.0 于 2026-10-26 产出，为非甲方签署版，随验收阶段按真机数据升版）
5. **安全验收**：权限矩阵测试 + 审计日志抽查 + 备份恢复演练

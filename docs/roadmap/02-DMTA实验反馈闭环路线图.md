## 1. 目标

将平台从“计算结果导出”推进为可审查的设计、制备、测试、分析（DMTA）反馈闭环。平台不替代 LIMS/ELN，而是保存与项目决策直接相关的候选、实验摘要、预测-实测关联和下一轮设计依据。

```text
设计/导入候选
  -> 标准化与筛选
  -> 预测、对接和重排
  -> 人工选择候选
  -> 合成/测试系统
  -> 实验结果受控回写
  -> 预测-实测比较
  -> 形成下一轮设计输入
```

## 2. 阶段范围

| 阶段 | 版本 | 平台能力 | 非目标 |
| --- | --- | --- | --- |
| 阶段 A | V1 | 固定分子身份、预测/评分语义、证据等级、导出候选清单 | 自动实验和模型再训练 |
| 阶段 B | V1.1 | 受控 CSV/JSON 导入 `assay_result@1`、候选决策记录、预测-实测比较、项目报告 | 原始仪器数据和样品库存管理 |
| 阶段 C | V2 | 外部 ELN/LIMS 引用、批次关联、项目验证汇总、模型质量看板 | 平台取代 ELN/LIMS |
| 阶段 D | 后续专项 | 审批后的再训练、主动学习和实验建议 | 无人工审查的自动实验闭环 |

## 3. 最小领域对象

| 对象 | 作用 | 关键关系 |
| --- | --- | --- |
| CandidateSet | 一次筛选或生成得到的候选集合 | 引用 `molecule_table@1` 不可变版本 |
| CandidateDecision | 人工选择、排除或保留候选的理由 | 关联分子、评分、操作者、时间和证据 |
| AssayResult | 实测值和 assay 语义 | 关联 molecule、endpoint、协议和来源摘要 |
| PredictionMeasurementLink | 可比较的预测-实测配对 | 校验 endpoint、单位和分子身份 |
| DesignCycle | 项目中的一轮 DMTA 复盘 | 聚合候选、实验结果和下一轮输入 |

## 4. 验收边界

阶段 B 至少验证：

1. 导入的实验结果可定位到不可变分子身份和来源文件摘要。
2. 平台拒绝或明确标记 endpoint、单位、分子身份无法对齐的预测-实测比较。
3. 候选表能够展示预测、评分、实测和证据等级，但不将其混为同一数值。
4. 项目报告能导出候选选择理由、工具/模型版本、输入输出 hash 和实验引用。
5. 外部 ELN/LIMS 仅保存引用和受控摘要，不绕过项目权限或复制不必要的原始实验数据。

## 5. 风险控制

- 预测优先级不等于实验活性；项目报告必须带有证据等级和适用域提示。
- 实验 endpoint、单位、protocol 和物种不一致时不得直接计算模型误差。
- 实验回写和模型评估需要科学负责人审核；平台只提供记录、校验和可复核视图。
- 再训练或主动学习必须单独立项，并保留数据快照、拆分策略、审批和回滚路径。

### 修复详情

#### 修复 1: 添加 `get_async_session()` 函数

**文件**: `backend/app/database/session.py`

```python
async def get_async_session() -> AsyncGenerator[AsyncSession, None]:
    """获取异步数据库会话（用于非依赖注入场景）"""
    async with async_session_factory() as session:
        try:
            yield session
        except Exception:
            await session.rollback()
            raise
        finally:
            await session.close()
```

**作用**: 为 `RemoteAPIExecutor._process_output_files()` 提供数据库会话。

---

#### 修复 2: 请求数据格式支持

**文件**: `backend/app/tasks/executor.py`

**修改前**:
```python
request_data = {
    "task_id": str(self.task.id),
    "params": {}
}
if self.task.inputs:
    request_data["params"] = self.task.inputs.params or {}
```

**修改后**:
```python
request_data = {
    "task_id": str(self.task.id)
}

if self.task.inputs:
    input_params = self.task.inputs.params or {}

    # 分离 params 和 input_files
    if "params" in input_params and "input_files" in input_params:
        request_data["params"] = input_params["params"]
        request_data["input_files"] = input_params["input_files"]
    else:
        # 向后兼容
        request_data["params"] = input_params
```

**作用**: 支持 LVPocket API 期望的数据格式：
```json
{
  "task_id": "xxx",
  "params": {
    "threshold": 0.5,
    "min_size": 50,
    ...
  },
  "input_files": {
    "protein_file": "https://..."
  }
}
```

#### 修复 3: 输出文件字段名兼容

**文件**: `backend/app/tasks/executor.py`

**修改前**:

filename = file_info.get("filename", f"output_{uuid.uuid4()}.dat")

## 工具调用流程

### 数据流程图

```
用户提交任务
    ↓
TaskInput (params + input_files)
    ↓
RemoteAPIExecutor._prepare_request_data()
    ↓
HTTP POST → LVPocket Service
    ↓
LVPocket 返回结果 (result + output_files)
    ↓
RemoteAPIExecutor._process_output_files()
    ↓
下载输出文件 → 保存到本地存储 → 创建 File 记录
    ↓
TaskOutput (result + file_ids)
    ↓
返回给用户
```

## 结果保存与返回

### 输出文件处理流程

1. **LVPocket 返回输出文件列表**:
   ```json
   {
     "success": true,
     "result": {
       "num_pockets": 3,
       ...
     },
     "output_files": [
       {
         "name": "pocket_1.mol2",
         "format": "mol2",
         "size": 12345,
         "url": "http://lvpocket-service:8000/outputs/xxx/pocket_1.mol2"
       }
     ]
   }
   ```

2. **RemoteAPIExecutor 处理**:
   - 从 `url` 下载文件内容
   - 计算 SHA256 哈希
   - 创建 `File` 数据库记录
   - 保存到本地存储 (`storage/uploads/`)
   - 返回文件 ID 列表

3. **保存到 TaskOutput**:
   ```python
   TaskOutput(
       task_id=task.id,
       result={
           "success": true,
           "result": {...},
           "output_file_ids": ["file-id-1", "file-id-2"]
       },
       file_ids=["file-id-1", "file-id-2"]
   )
   ```

### 文件存储结构

```
storage/uploads/
├── ab/
│   └── abc123_pocket_1.mol2
├── cd/
│   └── cde456_pocket_2.mol2
└── ...
```

**命名规则**: `{file_id[:2]}/{file_id}_{filename}`

### 用户下载文件

```bash
# 获取任务输出
curl http://localhost:8000/api/v1/tasks/$TASK_ID \
  -H "Authorization: Bearer YOUR_TOKEN"

# 响应包含 file_ids
{
  "outputs": {
    "result": {...},
    "file_ids": ["file-id-1", "file-id-2"]
  }
}

# 下载文件
curl http://localhost:8000/api/v1/files/file-id-1/download \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -o pocket_1.mol2
```

from app.models.users import User, UserRole, UserStatus

下面给你两份交付物（都按你当前约束：**外部工具服务接入（Remote API）+ 私有化部署 + 输出以 3D/CSV/图片为主** 来设计）：

1. **平台自身 API 的 OpenAPI 文档草案（YAML）**
2. **数据库 ERD + Alembic 迁移策略 + PostgreSQL 初始化脚本（schema + seed）**

> 说明：我把所有核心实体的 `id` 统一设计为 `UUID`（私有化部署下也推荐），避免 ID 可枚举；并且便于以后做文件下载、回调等“对外暴露链接”的安全性。你如果更想用自增 bigint，也很容易替换（迁移策略里我会说怎么改）。

---

# 1) 平台自身 API：OpenAPI 3.0 草案（openapi.yaml）

> 你们实现时可以先照这个落 FastAPI 路由，再按实际字段微调。

# 3) 迁移策略：推荐 Alembic（FastAPI + SQLAlchemy 2.0）

## 3.1 为什么这里推荐 Alembic

* 你前面平台设计倾向 FastAPI（Python），工具生态也多 Python，Alembic 迁移最顺手
* JSONB、索引、约束、枚举（CHECK）等都能精细控制
* 私有化部署场景下，用 “**容器启动时初始化一次 + Alembic 持续演进**” 很稳

## 3.2 目录与流程建议

建议结构：

```
backend/
  app/
    db/
      base.py            # DeclarativeBase
      session.py         # engine/session
      models/            # SQLAlchemy models
    api/                 # routers
  alembic/
    versions/
  alembic.ini
```

初始化步骤（示例）：

1. `alembic init alembic`
2. 在 `alembic/env.py` 里引入 `Base.metadata`
3. 第一次建表：

   * 方式 A（推荐）：写好 models 后 `alembic revision --autogenerate -m "init"`
   * 方式 B：直接手写 `op.create_table`（更可控）

上线/部署时：

* 每次发布：先跑 `alembic upgrade head`
* 回滚：`alembic downgrade -1`（仅在你确认安全时用）

## 3.3 迁移策略关键点（避免踩坑）

1. **枚举字段（role/status/visibility/status 等）**：
   MVP 建议用 `TEXT + CHECK`，避免 PostgreSQL ENUM 之后改 enum 值很麻烦。
2. **OpenAPI schema / params / outputs**：
   用 `JSONB`，并且对检索字段（如 tags、status、created_at）建索引即可。
3. **updated_at 自动更新**：
   用触发器（SQL）或在 ORM 层事件钩子；私有化部署推荐 DB 触发器更一致。
4. **文件表清理（expires_at）**：
   不靠 DB 自动清理，靠一个定时任务（Celery beat / cronjob）扫过期对象并删 MinIO/S3 与 DB 记录。

## 4.1 001_schema.sql

```sql
-- 001_schema.sql
-- PostgreSQL >= 13
BEGIN;

-- UUID
CREATE EXTENSION IF NOT EXISTS pgcrypto;

-- Case-insensitive email
CREATE EXTENSION IF NOT EXISTS citext;

-- Updated_at trigger helper
CREATE OR REPLACE FUNCTION set_updated_at()
RETURNS trigger AS $$
BEGIN
  NEW.updated_at = now();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- -----------------------
-- users
-- -----------------------
CREATE TABLE IF NOT EXISTS users (
  id            uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  email         citext NOT NULL UNIQUE,
  password_hash text NOT NULL,
  display_name  text NOT NULL,
  role          text NOT NULL DEFAULT 'user' CHECK (role IN ('user','admin')),
  status        text NOT NULL DEFAULT 'active' CHECK (status IN ('active','disabled')),
  created_at    timestamptz NOT NULL DEFAULT now(),
  updated_at    timestamptz NOT NULL DEFAULT now()
);

DROP TRIGGER IF EXISTS trg_users_updated_at ON users;
CREATE TRIGGER trg_users_updated_at
BEFORE UPDATE ON users
FOR EACH ROW EXECUTE FUNCTION set_updated_at();

CREATE INDEX IF NOT EXISTS idx_users_created_at ON users(created_at);

-- -----------------------
-- tools
-- -----------------------
CREATE TABLE IF NOT EXISTS tools (
  id                uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  owner_id          uuid NOT NULL REFERENCES users(id),
  name              text NOT NULL,
  slug              text NOT NULL UNIQUE,
  description       text,
  visibility        text NOT NULL DEFAULT 'public' CHECK (visibility IN ('public','private')),
  publish_status    text NOT NULL DEFAULT 'enabled' CHECK (publish_status IN ('enabled','disabled')),
  current_version_id uuid,
  created_at        timestamptz NOT NULL DEFAULT now(),
  updated_at        timestamptz NOT NULL DEFAULT now()
);

DROP TRIGGER IF EXISTS trg_tools_updated_at ON tools;
CREATE TRIGGER trg_tools_updated_at
BEFORE UPDATE ON tools
FOR EACH ROW EXECUTE FUNCTION set_updated_at();

CREATE INDEX IF NOT EXISTS idx_tools_owner ON tools(owner_id);
CREATE INDEX IF NOT EXISTS idx_tools_visibility ON tools(visibility, publish_status);
CREATE INDEX IF NOT EXISTS idx_tools_created_at ON tools(created_at DESC);

-- -----------------------
-- tool_versions
-- -----------------------
CREATE TABLE IF NOT EXISTS tool_versions (
  id                   uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  tool_id              uuid NOT NULL REFERENCES tools(id) ON DELETE CASCADE,
  version              text NOT NULL,
  base_url             text NOT NULL,
  method               text NOT NULL CHECK (method IN ('GET','POST','PUT','PATCH','DELETE')),
  path                 text NOT NULL,
  operation_id         text,
  openapi_schema       jsonb NOT NULL,
  runner_type          text NOT NULL DEFAULT 'remote' CHECK (runner_type IN ('remote')),
  auth_type            text NOT NULL DEFAULT 'none' CHECK (auth_type IN ('none','api_key')),
  estimated_runtime_sec int NOT NULL DEFAULT 30 CHECK (estimated_runtime_sec > 0),
  created_by           uuid NOT NULL REFERENCES users(id),
  created_at           timestamptz NOT NULL DEFAULT now(),
  UNIQUE(tool_id, version)
);

CREATE INDEX IF NOT EXISTS idx_tool_versions_tool ON tool_versions(tool_id, created_at DESC);

-- tools.current_version_id -> tool_versions.id  (add FK after both exist)
ALTER TABLE tools
  DROP CONSTRAINT IF EXISTS fk_tools_current_version;
ALTER TABLE tools
  ADD CONSTRAINT fk_tools_current_version
  FOREIGN KEY (current_version_id) REFERENCES tool_versions(id);

-- -----------------------
-- tags / tool_tag_map
-- -----------------------
CREATE TABLE IF NOT EXISTS tags (
  id    uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  name  text NOT NULL UNIQUE
);

CREATE TABLE IF NOT EXISTS tool_tag_map (
  tool_id uuid NOT NULL REFERENCES tools(id) ON DELETE CASCADE,
  tag_id  uuid NOT NULL REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (tool_id, tag_id)
);

CREATE INDEX IF NOT EXISTS idx_tool_tag_tag ON tool_tag_map(tag_id);

-- -----------------------
-- tool_favorites
-- -----------------------
CREATE TABLE IF NOT EXISTS tool_favorites (
  user_id    uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  tool_id    uuid NOT NULL REFERENCES tools(id) ON DELETE CASCADE,
  created_at timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY (user_id, tool_id)
);

CREATE INDEX IF NOT EXISTS idx_fav_tool ON tool_favorites(tool_id);

-- -----------------------
-- tool_examples
-- -----------------------
CREATE TABLE IF NOT EXISTS tool_examples (
  id              uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  tool_version_id uuid NOT NULL REFERENCES tool_versions(id) ON DELETE CASCADE,
  name            text NOT NULL,
  params          jsonb NOT NULL,
  created_at      timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX IF NOT EXISTS idx_examples_version ON tool_examples(tool_version_id);

-- -----------------------
-- tool_api_keys
-- -----------------------
CREATE TABLE IF NOT EXISTS tool_api_keys (
  id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  tool_id    uuid NOT NULL REFERENCES tools(id) ON DELETE CASCADE,
  key_hash   text NOT NULL,
  name       text,
  status     text NOT NULL DEFAULT 'active' CHECK (status IN ('active','revoked')),
  created_at timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX IF NOT EXISTS idx_tool_api_keys_tool ON tool_api_keys(tool_id);

-- -----------------------
-- files
-- -----------------------
CREATE TABLE IF NOT EXISTS files (
  id           uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  owner_id     uuid REFERENCES users(id),
  source_type  text NOT NULL CHECK (source_type IN ('user_input','tool_output')),
  bucket       text NOT NULL,
  object_key   text NOT NULL,
  filename     text NOT NULL,
  content_type text,
  size_bytes   bigint NOT NULL CHECK (size_bytes >= 0),
  sha256       text,
  is_public    boolean NOT NULL DEFAULT false,
  created_at   timestamptz NOT NULL DEFAULT now(),
  expires_at   timestamptz,
  UNIQUE(bucket, object_key)
);

CREATE INDEX IF NOT EXISTS idx_files_owner ON files(owner_id, created_at DESC);
CREATE INDEX IF NOT EXISTS idx_files_expires ON files(expires_at);

-- -----------------------
-- tasks / inputs / outputs / logs
-- -----------------------
CREATE TABLE IF NOT EXISTS tasks (
  id              uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         uuid REFERENCES users(id),
  tool_id         uuid NOT NULL REFERENCES tools(id),
  tool_version_id uuid NOT NULL REFERENCES tool_versions(id),
  job_name        text,
  status          text NOT NULL DEFAULT 'PENDING' CHECK (status IN ('PENDING','RUNNING','SUCCESS','FAILURE','CANCELED')),
  task_mode       text NOT NULL DEFAULT 'sync' CHECK (task_mode IN ('sync','async')),
  created_at      timestamptz NOT NULL DEFAULT now(),
  started_at      timestamptz,
  finished_at     timestamptz,
  error_message   text,
  cost_units      int NOT NULL DEFAULT 0
);

CREATE INDEX IF NOT EXISTS idx_tasks_user ON tasks(user_id, created_at DESC);
CREATE INDEX IF NOT EXISTS idx_tasks_tool ON tasks(tool_id, created_at DESC);
CREATE INDEX IF NOT EXISTS idx_tasks_status ON tasks(status);

CREATE TABLE IF NOT EXISTS task_inputs (
  task_id    uuid PRIMARY KEY REFERENCES tasks(id) ON DELETE CASCADE,
  params     jsonb NOT NULL,
  file_ids   jsonb,
  created_at timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE IF NOT EXISTS task_outputs (
  task_id    uuid PRIMARY KEY REFERENCES tasks(id) ON DELETE CASCADE,
  raw_output jsonb,
  normalized jsonb,
  created_at timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE IF NOT EXISTS task_logs (
  id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  task_id    uuid NOT NULL REFERENCES tasks(id) ON DELETE CASCADE,
  level      text NOT NULL DEFAULT 'INFO',
  message    text NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX IF NOT EXISTS idx_task_logs_task ON task_logs(task_id, created_at);

COMMIT;
```

## app/api/deps.py（依赖：Bearer / Tool API Key）

```python
from typing import Optional
from fastapi import Depends, Header, HTTPException, status
from fastapi.security import OAuth2PasswordBearer

from app.schemas.common import User

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/v1/auth/login", auto_error=False)

def get_current_user_optional(token: Optional[str] = Depends(oauth2_scheme)) -> Optional[User]:
    """
    开发态：只要带了 Authorization: Bearer xxx 就认为已登录。
    你上线时：这里替换成 JWT 校验 + DB 查用户。
    """
    if not token:
        return None

    # Demo user
    return User(
        id="00000000-0000-0000-0000-000000000001",
        email="dev@example.com",
        display_name="Dev User",
        role="admin",
        status="active",
        created_at="2025-01-01T00:00:00Z",
        updated_at="2025-01-01T00:00:00Z",
    )

def get_current_user(user: Optional[User] = Depends(get_current_user_optional)) -> User:
    if not user:
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Not authenticated")
    return user

def require_tool_api_key(x_tool_api_key: Optional[str] = Header(default=None, alias="X-TOOL-API-KEY")) -> str:
    """
    工具回调/工具上传文件使用。
    上线时：对 x_tool_api_key 做哈希比对/状态检查，并绑定 tool_id 权限。
    """
    if not x_tool_api_key:
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Missing X-TOOL-API-KEY")
    return x_tool_api_key
```
